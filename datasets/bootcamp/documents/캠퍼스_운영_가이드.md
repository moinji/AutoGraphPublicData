## 1. 캠퍼스 총괄 개요

본 코딩 부트캠프는 수도권 2개소(강남, 판교)와 지방 1개소(부산) 총 3개 캠퍼스를 운영하고 있습니다. 각 캠퍼스는 교육운영팀이 일상 운영을 담당하며, 시설 유지보수 및 예산 관리는 경영지원팀에서 총괄합니다.

### 캠퍼스별 운영 과정 배정

| 캠퍼스 | 운영 과정 | 최대 수용 인원 |
|--------|----------|--------------|
| 강남캠퍼스 | 풀스택 웹개발(30명), 데이터 사이언스 입문(25명), 프론트엔드 심화(25명) | 80명 |
| 판교캠퍼스 | AI/ML 엔지니어링(20명), 클라우드 DevOps(20명) | 40명 |
| 부산캠퍼스 | 백엔드 Java Spring(30명) | 30명 |

## 7. 안전 및 보안

### 7.1 출입 관리

- 수강생 ID 카드: NFC 기반 출입 (등록 시 발급)
- 야간/주말 출입: 카드키로 자율학습 공간만 접근 가능
- 강의실/서버실: 수업 시간 외 잠금 (강사 동행 시만 해제)
- 방문자: 안내 데스크에서 임시 출입증 발급 (본인 확인 필수)

### 7.2 CCTV 운영

- 설치 위치: 출입구, 복도, 공용 공간 (강의실 내부 미설치)
- 보관 기간: 30일
- 열람 요청: 경영지원팀 오진우 매니저에게 서면 요청

### 7.3 비상 대응

| 상황 | 대응 절차 |
|------|----------|
| 화재 | 비상벨 → 대피 (계단 이용) → 1층 집결 → 119 신고 |
| 지진 | 테이블 아래 대피 → 흔들림 멈추면 계단 대피 → 집결 |
| 정전 | 비상 조명 자동 점등 → 안내 데스크 지시 대기 |
| 의료 응급 | 119 신고 → AED 위치 확인 (각 층 복도) → 응급 처치 |
| 시설 고장 | 안내 데스크 신고 → 경영지원팀 접수 → 수리 |

### 7.4 소방 훈련

- 분기별 1회 합동 소방 훈련 실시 (의무 참석)
- 각 층 소화기 위치: 복도 양 끝 + 서버실 옆
- AED 위치: 각 층 엘리베이터 옆 벽면
