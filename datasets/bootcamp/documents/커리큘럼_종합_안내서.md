| 등급 | 점수 범위 | 수료 여부 |
|------|----------|----------|
| S (Exceptional) | 95점 이상 | 수료 + 우수 수료증 |
| A (Excellent) | 85~94점 | 수료 |
| B (Good) | 75~84점 | 수료 |
| C (Satisfactory) | 65~74점 | 수료 |
| F (Fail) | 64점 이하 | 미수료 |

### 평가 원칙
1. 모든 프로젝트는 GitHub 제출을 원칙으로 하며, 커밋 히스토리를 통해 개발 과정을 확인합니다.
2. 팀 프로젝트의 경우 개인 기여도를 피어 리뷰를 통해 산정합니다.
3. 코드 품질 (클린 코드, 테스트 커버리지, 문서화)은 전체 점수의 20%를 반영합니다.
4. 출석률 80% 미만 시 과정 평가와 무관하게 미수료 처리됩니다.
