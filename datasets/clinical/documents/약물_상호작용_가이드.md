# 약물 상호작용 가이드라인

## 개요

본 가이드라인은 임상연구병원에서 처방 시 주의해야 할 주요 약물 상호작용을 정리한 문서입니다. 모든 처방 의사는 다중 약물 처방 시 반드시 이 가이드라인을 참조해야 합니다.

## 주요 상호작용

### 1. Atorvastatin + Amlodipine (중등도)

- **기전**: CYP3A4 경쟁적 대사 억제
- **위험**: Atorvastatin 혈중 농도 상승 → 횡문근융해증 위험 증가
- **권고**: Atorvastatin 일일 20mg 이하로 제한. 근육통 발생 시 즉시 CK 검사
- **모니터링**: 병용 개시 4주 후 AST/ALT, CK 검사

### 2. Amoxicillin + Metformin (경미)

- **기전**: 장내 흡수 경쟁
- **위험**: Metformin 흡수율 일시적 감소 (임상적 유의성 낮음)
- **권고**: 투약 간격 2시간 이상 유지 권장
- **모니터링**: 공복혈당 추가 모니터링 불필요

### 3. Sertraline + Tramadol (심각)

- **기전**: 세로토닌 재흡수 이중 억제 → 세로토닌 증후군 위험
- **위험**: 고열, 근긴장, 경련, 의식 변화 가능
- **권고**: **병용 금기**. 대안 진통제(Acetaminophen, NSAIDs) 사용
- **모니터링**: 불가피한 병용 시 24시간 활력징후 모니터링

### 4. Pembrolizumab + 기타 면역억제제 (심각)

- **기전**: 면역관문억제제의 효과 감소
- **위험**: 항암 효과 저하, 면역 관련 부작용 패턴 변화
- **권고**: 코르티코스테로이드 병용 시 용량 최소화. 다른 면역억제제 병용 전 종양내과 협진 필수
- **모니터링**: 면역 관련 이상반응(irAE) 정기 평가

## 다중 약물 처방 원칙

1. **최소 약물 원칙**: 필요한 최소한의 약물만 처방
2. **상호작용 조회**: 3개 이상 약물 병용 시 반드시 약물상호작용 DB 조회
3. **환자 교육**: 상호작용 위험이 있는 처방 시 환자에게 증상 설명
4. **정기 검토**: 장기 처방 환자는 3개월마다 처방 적정성 검토

## 보고 체계

약물 상호작용으로 인한 이상반응 발생 시:
1. 즉시 담당 주치의 보고
2. 약물감시센터(PV Center)에 이상반응 보고서 제출
3. 72시간 이내 의무기록에 상호작용 관련 사항 기록
