# 임상시험 운영 절차 매뉴얼

## 1. 임상시험 개요

임상연구병원은 현재 6건의 임상시험을 동시 운영하고 있으며, Phase 1부터 Phase 3까지 다양한 단계의 연구를 수행합니다.

### 현재 진행 중인 임상시험

| 시험명 | 단계 | 스폰서 | 상태 |
|--------|------|--------|------|
| 고혈압 신약 임상 2상 | Phase 2 | 한국MSD | 모집 중 |
| 면역항암제 병용 3상 | Phase 3 | 화이자코리아 | 진행 중 |
| 우울증 디지털 치료 1상 | Phase 1 | 뉴로핏 | 모집 중 |
| 당뇨 GLP-1 수용체 작용제 | Phase 2 | 일라이릴리 | 진행 중 |
| 소아 천식 흡입제 | Phase 3 | 아스트라제네카 | 모집 완료 |
| AI 진단보조 기기 | Phase 1 | 뷰노 | 승인 대기 |

## 2. 환자 등록 절차

### 2.1 스크리닝

1. **적격성 평가**: 포함/제외 기준에 따라 환자 적격성 판단
2. **동의서 취득**: IRB 승인 동의서를 사용하여 서면 동의 획득
3. **스크리닝 검사**: 기본 혈액검사, 심전도, 활력징후 측정
4. **등록 확정**: 스크리닝 통과 시 무작위 배정

### 2.2 등록 시 주의사항

- 동일 환자의 **다중 시험 참여 금지** (washout period 최소 30일)
- 담당 의사가 직접 동의 과정 수행 (위임 불가)
- 스크리닝 실패 시 재스크리닝은 1회만 허용

## 3. 의뢰(Referral) 절차

### 3.1 내부 의뢰

- 타 진료과 협진이 필요한 경우, EMR에서 의뢰서를 작성합니다
- **의뢰 의사**(referring doctor)가 작성하고 **수진 의사**(receiving doctor)가 접수합니다
- 의뢰서에는 의뢰 사유, 현재 진단명, 희망 협진 내용을 기재합니다

### 3.2 의뢰 현황

- 내과 → 외과: 수술 적응증 평가 의뢰가 가장 많음
- 종양내과 → 정신건강의학과: 암환자 심리 지원 의뢰 증가 추세
- 소아청소년과 → 신경과: 소아 경련 환자 의뢰

### 3.3 긴급 의뢰

응급 상황에서는 구두 의뢰 후 24시간 이내 서면 의뢰서 작성으로 대체할 수 있습니다.

## 4. 연구 논문 발표

### 4.1 논문 작성 원칙

- 임상시험 결과 논문의 **책임저자(lead author)**는 해당 시험의 PI(Principal Investigator)가 됩니다
- PI가 아닌 의사가 주도한 하위 분석은 PI 승인 후 발표 가능
- 모든 논문은 출판 전 IRB 및 스폰서 검토 필수

### 4.2 최근 발표 실적

| 논문 제목 | 저널 | PI | 관련 시험 |
|-----------|------|-----|-----------|
| 고혈압 환자 Amlodipine 반응성 바이오마커 연구 | Korean J Med | 김정호 교수 | 고혈압 신약 임상 2상 |
| 면역항암제 병용요법 Phase 2 결과 | J Clin Oncol | 이수민 교수 | 면역항암제 병용 3상 |
| 소아 천식 장기 관리에서 흡입 스테로이드 효과 | Pediatr Allergy | 오민지 교수 | 소아 천식 흡입제 |
