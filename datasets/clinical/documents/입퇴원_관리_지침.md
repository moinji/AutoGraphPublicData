# 입퇴원 관리 지침

## 1. 입원 절차

### 1.1 입원 경로

환자는 다음 3가지 경로로 입원합니다:

1. **외래 경유 입원**: 외래 진료 후 담당의가 입원 결정 → 입원원무과 접수 → 병동 배정
2. **응급 입원**: 응급실 경유 → 응급의학과 의사가 입원 결정 → 해당 진료과 담당의 지정
3. **전원 입원**: 타 병원에서 전원 → 접수 시 전원 사유서 및 진료정보 교환 동의서 필요

### 1.2 병동 배정 기준

| 병동 | 진료과 | 병상 수 | 유형 |
|------|--------|---------|------|
| 내과 일반병동 | 내과 | 40 | 일반 |
| 외과 병동 | 외과 | 30 | 수술 후 관리 |
| 소아 병동 | 소아청소년과 | 20 | 소아 전용 |
| 신경과 병동 | 신경과 | 25 | 일반 |
| 종양 병동 | 종양내과 | 30 | 항암 치료 |
| 정신건강 병동 | 정신건강의학과 | 15 | 폐쇄 병동 |

### 1.3 담당의 지정

- **attending_doctor**: 입원 환자의 주치의. 입원 기간 동안 모든 의료 결정의 책임
- 수술 환자의 경우 외과 의사가 attending_doctor, 내과 질환 동반 시 내과 협진 의뢰
- 임상시험 참여 환자는 PI가 attending_doctor를 겸임하거나 별도 지정

## 2. 입원 중 관리

### 2.1 일일 회진

- 오전 8:00~9:00 — 담당의 회진
- 오후 5:00 — 당직의 야간 인계 회진
- 중환자의 경우 2시간 간격 활력징후 체크

### 2.2 검사 오더

입원 환자의 검사는 담당의가 EMR에서 오더합니다:

- **기본 입원 검사**: CBC, 전해질, 간기능(AST/ALT), 신기능(BUN/Cr), 흉부 X선
- **추가 검사**: 담당의 판단에 따라 특수 검사 오더
- **긴급 검사**: STAT 오더 시 1시간 이내 결과 확인

### 2.3 처방 관리

- 정규 처방: 매일 오전 회진 후 갱신
- PRN(필요시) 처방: 간호사가 판단하여 투여, 사후 담당의 확인
- **다제 처방 환자**: 5개 이상 약물 복용 시 약사 상담 의무화

## 3. 퇴원 절차

### 3.1 퇴원 기준

1. 활력징후 안정 (체온 37.5°C 미만, 24시간 이상)
2. 경구 식이 가능
3. 독립 보행 가능 (수술 환자)
4. 퇴원 후 관리 계획 수립 완료

### 3.2 퇴원 서류

- 퇴원 요약서 (담당의 작성)
- 퇴원 처방전 (외래 약 처방)
- 다음 외래 예약 확인서
- 퇴원 간호 교육 기록

### 3.3 평균 재원일수

| 진료과 | 평균 재원일수 | 비고 |
|--------|-------------|------|
| 내과 | 7.2일 | 폐렴 환자 평균 10일 |
| 외과 | 5.8일 | 복강경 수술 3-4일, 개복 7-10일 |
| 소아청소년과 | 4.5일 | |
| 신경과 | 8.1일 | 뇌졸중 재활 포함 시 14일+ |
| 종양내과 | 6.3일 | 항암 주기별 입원 |
| 정신건강의학과 | 21.0일 | 자의 퇴원 기준 충족 필요 |
