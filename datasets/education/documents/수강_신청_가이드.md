## 제3장. 선수과목(Prerequisites) 체계

### 3.1 선수과목 이수 요건

수강 신청 시 선수과목 이수 여부가 시스템에서 자동 확인됩니다. 선수과목을 이수하지 않은 경우 수강 신청이 차단됩니다.

| 과목 | 선수과목 | 비고 |
|------|---------|------|
| CS201 자료구조 | CS101 프로그래밍 기초 (필수) | D+ 이상 이수 |
| CS301 인공지능 개론 | CS201 자료구조 (필수) | C0 이상 이수 |
| CS301 인공지능 개론 | MATH101 미적분학 (권장) | 미이수 시 경고만 |
| CS401 데이터베이스 | CS201 자료구조 (필수) | C0 이상 이수 |
| DES201 UI/UX 디자인 | 디자인 기초 (권장) | 미이수 시 면담 필요 |
| ENG201 비즈니스 영어 | 영어회화 기초 (권장) | 미이수 시 배치고사 |

### 3.2 선수과목 면제 절차

특별한 사유가 있는 경우 다음 절차를 통해 선수과목 면제를 신청할 수 있습니다.

1. 해당 과목 담당교수와 면담 실시
2. 면담 확인서 및 면제 사유서 작성
3. 학과 사무실에 면제 신청서 제출 (증빙서류 첨부)
4. 학과장 승인 후 교무처에 면제 결과 통보
5. 수강 신청 시스템에 면제 사항 반영 (최소 3영업일 소요)

## 제4장. 수강 신청 절차

### 4.1 수강 신청 시스템 접속

1. 본교 홈페이지(www.kmu.ac.kr) 접속
2. 통합정보시스템 로그인 (학번/비밀번호)
3. 학사관리 > 수강신청 메뉴 선택
4. 개설과목 조회 및 수강 신청

### 4.2 수강 신청 규칙

- 학기당 최소 12학점, 최대 21학점까지 신청 가능
- 직전 학기 GPA 4.0 이상인 경우 최대 24학점까지 신청 가능 (한서연 학생은 GPA 4.3으로 24학점 신청 자격 충족)
- 시간표 중복 과목은 신청 불가
- 동일 과목 재수강은 직전 성적이 C+ 이하인 경우만 가능
- 타 학과 전공과목은 해당 학과 정원의 10% 이내에서 수강 가능

### 4.3 수강 정정 및 취소

#### 수강 정정 (2026.03.02 ~ 03.06)
- 개강 첫째 주에 한하여 과목 변경 가능

- 성적표에 'W'(Withdrawal)로 표기
- 학기당 최대 1과목까지 가능
- GPA에는 영향 없음
- 철회 시 해당 학점은 이수 학점에서 제외

## 제6장. 유의사항

### 6.1 수강 신청 전 확인사항

1. 졸업요건 이수현황 확인 (학과별 필수 과목 이수 여부)
2. 선수과목 이수 확인 (특히 CS201 -> CS301/CS401 선수 체계)
3. 시간표 충돌 여부 확인
4. 강의실 위치 확인 (건물 간 이동 시간 최소 15분 확보)
5. 실습 분반 선택 확인 (공학관 301호 실습실은 30명 제한)

### 6.2 자주 묻는 질문

Q: 컴퓨터공학과가 아닌데 CS101 프로그래밍 기초를 수강할 수 있나요?
A: 네, 교양선택으로 수강 가능합니다. 다만 정원의 10%인 6명까지만 타 학과 학생이 수강할 수 있습니다.

Q: 2025-2학기에 CS101을 이수했는데, 바로 CS301을 수강할 수 있나요?
A: 아닙니다. CS301의 선수과목은 CS201이므로, CS201을 먼저 이수해야 합니다. 선수과목 체계는 CS101 -> CS201 -> CS301/CS401 순서입니다.

Q: 미적분학(MATH101)을 이수하지 않아도 인공지능 개론(CS301)을 수강할 수 있나요?
A: 미적분학은 권장 선수과목이므로 미이수 시에도 수강은 가능합니다. 다만 경사하강법, 확률분포 등의 수학적 내용이 포함되므로 미적분학 이수를 강력히 권장합니다.

Q: 수강 정원이 초과된 경우 어떻게 하나요?
A: 대기 순번제가 적용됩니다. 수강 취소자가 발생하면 대기 순번에 따라 자동 등록됩니다. 담당교수의 승인을 받으면 정원 외 수강도 가능하나, 강의실 수용인원을 초과할 수 없습니다.
