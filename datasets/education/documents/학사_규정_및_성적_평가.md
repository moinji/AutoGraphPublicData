# 한국미래대학교 학사 규정 및 성적 평가 기준

## 문서 정보

- 규정번호: ACAD-2026-003
- 제정일: 2020년 3월 1일
- 최종 개정일: 2026년 2월 1일 (제6차 개정)
- 주관부서: 교무처 학사관리팀
- 적용 대상: 학부 전 과정 재학생
- 본 규정은 학칙 제42조 내지 제78조에 근거하여 제정되었습니다.

---

## 제1장. 총칙

### 제1조 (목적)

본 규정은 한국미래대학교 학부 과정의 학사 운영, 성적 평가, 졸업 요건에 관한 세부 사항을 정하여 공정하고 체계적인 학사 관리를 도모함을 목적으로 한다.

### 제2조 (적용 범위)

1. 본 규정은 본교 학부 과정에 재학 중인 모든 학생에게 적용한다.
2. 컴퓨터공학과, 경영학과, 디자인학과, 수학과, 영어영문학과를 포함한 전 학과에 동일하게 적용한다.
3. 편입생, 복학생, 재입학생에게도 본 규정을 적용하되, 별도 경과조치가 있는 경우 해당 조항을 우선 적용한다.

### 제3조 (용어 정의)

| 용어 | 정의 |
|------|------|
| 학기 | 정규 수업이 이루어지는 기간 (봄학기: 3월~6월, 가을학기: 9월~12월) |
| 학점 | 과목별 학습 분량을 나타내는 단위 (1학점 = 주 1시간 강의 기준 16주) |
| GPA | Grade Point Average, 평점평균 (4.5 만점) |
| 이수구분 | 전공필수, 전공선택, 교양필수, 교양선택, 자유선택 |
| 재수강 | 이미 이수한 과목을 다시 수강하는 것 |

## 제2장. 수강 및 학점 이수

### 제4조 (학기당 이수 학점)

1. 학기당 최소 이수 학점: 12학점
2. 학기당 최대 이수 학점: 21학점
3. 직전 학기 GPA 4.0 이상인 학생: 최대 24학점까지 이수 가능
4. 계절학기: 최대 6학점
5. 졸업 학기 학생은 최소 이수 학점 제한을 받지 않음

참고: 수학과 2학년 한서연 학생(GPA 4.3)은 우수한 성적으로 2026-1학기에 24학점 이수가 가능하며, 이는 본 조 제3항에 따른 것이다.

### 제5조 (재수강)

1. 기존 성적이 C+(2.5) 이하인 과목에 한하여 재수강을 허용한다.
2. 재수강 시 기존 성적은 성적표에 "(재)" 표기와 함께 유지되나, GPA 계산 시 새 성적만 반영한다.
3. 재수강 최대 횟수는 과목당 1회이다.
4. 재수강으로 취득 가능한 최고 성적은 A0(4.0)이다.
5. 동일 학기에 재수강과 신규 수강을 합하여 최대 이수 학점을 초과할 수 없다.

### 제6조 (출석)

1. 수업 일수의 3/4 이상 출석하여야 해당 과목의 성적을 인정한다.
2. 결석 횟수가 수업 일수의 1/4을 초과할 경우 해당 과목은 자동 F 처리된다.
3. 공인 결석 사유: 질병(진단서 필요), 직계가족 경조사, 군 관련 소집, 학교 대표 활동
4. 공인 결석은 출석으로 인정하되, 과목당 최대 4회까지만 적용한다.
5. 지각 3회는 결석 1회로 간주한다.
6. 강의 시작 후 15분 이내 입실은 지각, 15분 초과 시 결석으로 처리한다.

## 제3장. 성적 평가

### 제7조 (성적 등급 및 평점)

| 등급 | 평점 | 점수 범위 | 의미 |
|------|------|-----------|------|
| A+ | 4.5 | 95~100 | 탁월 (Excellent) |
| A0 | 4.0 | 90~94 | 우수 (Very Good) |
| B+ | 3.5 | 85~89 | 양호 (Good) |
| B0 | 3.0 | 80~84 | 보통 이상 (Above Average) |
| C+ | 2.5 | 75~79 | 보통 (Average) |
| C0 | 2.0 | 70~74 | 보통 이하 (Below Average) |
| D+ | 1.5 | 65~69 | 미흡 (Poor) |
| D0 | 1.0 | 60~64 | 최저 합격 (Minimum Pass) |
| F | 0.0 | 0~59 | 불합격 (Fail) |
| P | - | Pass | 합격 (Pass/Fail 과목) |
| NP | - | Non-Pass | 불합격 (Pass/Fail 과목) |
| W | - | Withdrawal | 수강 철회 |
| I | - | Incomplete | 미완료 (추후 보완) |

### 제8조 (GPA 계산 방법)

GPA(평점평균)는 다음 공식에 따라 산출한다.

```
GPA = (각 과목의 학점 x 해당 과목 평점)의 합 / 총 이수 학점
```

산출 예시 (컴퓨터공학과 2학년 이영희 학생, GPA 4.1):

| 과목 | 학점 | 등급 | 평점 | 학점 x 평점 |
|------|------|------|------|-------------|
| 자료구조 (CS201) | 3 | A+ | 4.5 | 13.5 |
| 컴퓨터구조 | 3 | A0 | 4.0 | 12.0 |
| 운영체제 | 3 | A0 | 4.0 | 12.0 |
| 선형대수학 | 3 | B+ | 3.5 | 10.5 |
| 교양영어 | 2 | A+ | 4.5 | 9.0 |
| 한국사 | 2 | A0 | 4.0 | 8.0 |
| 합계 | 16 | | | 65.0 |

GPA = 65.0 / 16 = 4.0625 (반올림하여 4.1)

### 제9조 (상대평가 기준)

1. 수강 인원 30명 이상 과목: 상대평가 적용
   - A+ ~ A0: 30% 이내
   - A+ ~ B0: 70% 이내
   - F 비율 제한 없음

2. 수강 인원 10~29명 과목: 완화된 상대평가
   - A+ ~ A0: 40% 이내
   - F 비율 제한 없음

3. 수강 인원 9명 이하 과목: 절대평가 가능 (학과장 승인)

4. 실기/실습 비중 50% 이상 과목: 절대평가 가능 (UI/UX 디자인 DES201 등)

### 제10조 (성적 평가 요소)

각 과목의 성적 평가는 다음 요소를 종합하여 산출한다. 구체적 비율은 과목별 강의 계획서에 명시한다.

| 평가 요소 | 일반적 비율 | 비고 |
|-----------|------------|------|
| 중간고사 | 25~35% | 8주차 실시 |
| 기말고사 | 30~40% | 16주차 실시 |
| 과제/프로젝트 | 15~25% | 개인/팀 과제 |
| 출석 | 10~15% | 전자출결 시스템 |
| 발표/참여도 | 5~10% | 수업 참여 |
| 기타 (퀴즈 등) | 0~10% | 수시 평가 |

참고 사례:
- CS101 프로그래밍 기초 (김알고 교수): 중간 30%, 기말 35%, 실습과제 20%, 출석 10%, 퀴즈 5%
- BUS101 경영학원론 (박경영 교수): 중간 25%, 기말 30%, 팀프로젝트 25%, 출석 10%, 발표 10%
- DES201 UI/UX 디자인 (최디자인 교수): 포트폴리오 40%, 기말프로젝트 30%, 크리틱 참여 15%, 출석 15%

## 제4장. 학사 경고 및 제적

### 제11조 (학사 경고)

1. 학기 GPA가 1.5 미만인 경우 학사 경고를 부여한다.
2. 학사 경고는 학생 본인 및 보호자에게 서면으로 통지한다.
3. 학사 경고를 받은 학생은 다음 학기에 학과 지도교수와 필수 상담을 진행해야 한다.
4. 상담 결과에 따라 수강 학점 제한(최대 15학점), 학습 멘토링 프로그램 참여 등의 조치를 취할 수 있다.

### 제12조 (학사 경고 누적에 따른 제적)

1. 학사 경고 3회 연속 누적 시 제적 심사 대상이 된다.
2. 학사 경고 통산 4회 누적 시 제적 심사 대상이 된다.
3. 제적 심사는 학과 교수회의를 거쳐 교무위원회에서 최종 결정한다.
4. 제적 결정에 대해 30일 이내에 이의 신청을 할 수 있다.

### 제13조 (학사 유예)

1. 학사 경고를 받은 학생이 다음 학기에 GPA 2.5 이상을 달성한 경우 경고 이력을 1회 감면할 수 있다.
2. 감면은 재학 기간 중 최대 1회 적용 가능하다.

## 제6장. 학업 우수자 포상

### 제16조 (학장표창 - Dean's List)

1. 학기 GPA 4.0 이상이며, 해당 학기 15학점 이상 이수한 학생을 학장표창 대상으로 선정한다.
2. 학장표창 선정자는 다음 학기 등록금 50% 감면 장학금을 수여한다.
3. 학장표창 이력은 졸업증명서에 기재된다.

현재 학장표창(Dean's List) 등재 학생 (2025-2학기 기준):
- 한서연 (수학과 2학년, GPA 4.3) - 전체 수석
- 이영희 (컴퓨터공학과 2학년, GPA 4.1) - 학과 수석

### 제17조 (우등 졸업)

| 등급 | GPA 기준 | 칭호 | 비고 |
|------|----------|------|------|
| 최우등 | 4.3 이상 | Summa Cum Laude | 졸업생 상위 5% |
| 우등 | 4.0 이상 | Magna Cum Laude | 졸업생 상위 15% |
| 준우등 | 3.7 이상 | Cum Laude | 졸업생 상위 30% |

### 제18조 (조기 졸업)

1. 6학기(3년) 또는 7학기(3.5년) 만에 졸업 요건을 충족한 학생은 조기 졸업을 신청할 수 있다.
2. 조기 졸업 요건: 누적 GPA 4.0 이상, 졸업 요건 전부 충족, 학과장 추천
3. 조기 졸업 신청은 해당 학기 개강 전까지 교무처에 제출해야 한다.

## 제7장. 학적 변동

### 제19조 (휴학)

1. 일반 휴학: 학기 시작 후 4주 이내 신청, 학기당 최대 2학기
2. 군 휴학: 입영 통지서 제출, 복무 기간 전체
3. 질병 휴학: 진단서 필요, 학기 중 수시 신청 가능
4. 누적 최대 휴학 기간: 4학기 (군 휴학 제외)
5. 휴학 기간은 수업 연한에 포함되지 않는다.

### 제20조 (복학)

1. 복학은 휴학 종료 직후 학기에 자동 복학을 원칙으로 한다.
2. 복학 신청은 개강 2주 전까지 온라인으로 신청한다.
3. 2학기 이상 연속 휴학 후 복학하는 경우 학과 상담을 필수로 진행한다.
4. 교육과정 변경 시 경과조치에 따라 이수 과목을 재조정할 수 있다.

### 제21조 (전과)

1. 2학년 이상 재학생이 전과를 신청할 수 있다.
2. 전과 요건: 직전 2학기 연속 GPA 3.0 이상
3. 전과 정원: 각 학과 정원의 10% 이내
4. 전과 후 졸업 요건은 전과 학과의 요건을 따른다.
5. 기존 학과에서 이수한 과목의 인정 여부는 전과 학과 학과장이 결정한다.

## 제8장. 보칙

### 제22조 (성적 이의 신청)

1. 성적 공개 후 5영업일 이내에 성적 이의 신청을 할 수 있다.
2. 이의 신청은 해당 과목 담당교수에게 서면 또는 이메일로 제출한다.
3. 담당교수는 이의 신청 접수 후 5영업일 이내에 결과를 통보해야 한다.
4. 담당교수의 결정에 불복하는 경우 학과장에게 재심을 요청할 수 있다.
5. 최종 결정은 교무위원회에서 내리며, 이 결정에 대해서는 추가 이의를 제기할 수 없다.

### 제23조 (학사 부정행위)

1. 시험 중 부정행위(컨닝, 대리시험, 자료 무단 사용 등)가 적발된 경우 해당 과목은 F 처리한다.
2. 과제 표절이 확인된 경우 해당 과제는 0점 처리하며, 중복 적발 시 해당 과목 F 처리한다.
3. 부정행위 2회 이상 적발 시 학사 징계위원회에 회부한다.
4. 징계 종류: 근신(1개월), 유기정학(1~2학기), 무기정학, 제적

### 제24조 (규정 개정)

1. 본 규정의 개정은 교무위원회의 의결과 총장의 승인을 거쳐 시행한다.
2. 개정된 규정은 시행일 이후 입학한 학생부터 적용함을 원칙으로 하되, 재학생에게 유리한 개정사항은 소급 적용할 수 있다.
3. 본 규정에 명시되지 않은 사항은 학칙 및 관계 법령에 따른다.

## 부칙

2. 이전 규정(ACAD-2025-003)은 본 규정 시행일로부터 폐지한다.
