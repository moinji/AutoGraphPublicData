# 검사 안내서

**서울중앙병원 진단검사 및 영상검사 종합 안내서**

발행일: 2026년 3월 1일 | 개정판: 제6판 | 발행처: 서울중앙병원 진단검사의학과 / 영상의학과

---

## 안내 말씀

서울중앙병원에서 시행하는 주요 진단검사 및 영상검사에 대한 안내서입니다. 정확한 검사 결과를 얻기 위해 사전 준비사항을 반드시 숙지하시고, 궁금한 사항은 담당 의료진에게 문의하시기 바랍니다. 본원은 진단검사의학과(지하 1층)와 영상의학과(지하 1층)에서 연간 약 180,000건의 검사를 시행하고 있으며, 대한임상검사정도관리협회 인증을 받은 시설에서 운영됩니다.

## 제1장. 혈액검사

### 1-1. CBC (일반혈액검사, Complete Blood Count)

**검사 개요**

CBC(일반혈액검사)는 혈액 내 적혈구, 백혈구, 혈소판의 수와 형태를 분석하는 가장 기본적인 혈액검사입니다. 빈혈, 감염, 출혈성 질환, 백혈병 등 다양한 혈액 관련 질환을 선별하는 데 필수적인 검사로, 서울중앙병원의 모든 입원 환자와 수술 전 환자에게 시행됩니다.

**검사 정보**

| 항목 | 내용 |
|------|------|
| 검사명 | CBC (Complete Blood Count, 일반혈액검사) |
| 검체 | 정맥혈 3mL (EDTA 튜브, 보라색 뚜껑) |
| 금식 여부 | 불필요 (식사와 무관하게 채혈 가능) |
| 검사 소요시간 | 약 30분~1시간 |
| 결과 보고 | 당일 (응급: 30분 이내) |
| 검사 장소 | 진단검사의학과 (지하 1층 채혈실) |
| 채혈 시간 | 평일 07:00~17:00 / 토요일 07:00~12:00 / 응급: 24시간 |
| 비용 | 건강보험 적용 시 약 4,500원 (본인부담금 기준) |

**정상 참고치**

| 검사 항목 | 정상 범위 (성인 남성) | 정상 범위 (성인 여성) | 소아 참고치 | 단위 |
|----------|---------------------|---------------------|-----------|------|
| 백혈구 (WBC) | 4,000~10,000 | 4,000~10,000 | 5,000~15,000 (영유아) | /uL |
| 적혈구 (RBC) | 4.5~5.5 | 4.0~5.0 | 연령별 상이 | x10^6/uL |
| 혈색소 (Hb) | 13.0~17.0 | 12.0~16.0 | 11.0~14.0 | g/dL |
| 헤마토크릿 (Hct) | 39~52 | 36~48 | 33~42 | % |
| 혈소판 (PLT) | 150,000~400,000 | 150,000~400,000 | 150,000~400,000 | /uL |
| MCV | 80~100 | 80~100 | 70~86 | fL |
| MCH | 27~33 | 27~33 | 23~31 | pg |
| MCHC | 32~36 | 32~36 | 32~36 | g/dL |

**결과 해석 가이드**

- **백혈구 증가 (>10,000/uL):** 세균 감염, 염증, 스트레스 반응, 백혈병 가능. 소아과 박소아 전문의는 박민준(2018년생) 및 윤서준(2020년생) 등 소아 환자의 발열 시 CBC를 통해 세균 감염 여부를 감별합니다. 소아의 경우 정상 범위가 성인보다 높으므로 연령별 참고치를 적용합니다.
- **백혈구 감소 (<4,000/uL):** 바이러스 감염, 골수 억제, 약물 부작용 가능.
- **혈색소 감소 (남 <13.0, 여 <12.0):** 빈혈. 철결핍성 빈혈, 만성 질환에 의한 빈혈, 출혈 등 원인 감별 필요.
- **혈소판 감소 (<150,000/uL):** 출혈 경향 증가. 수술 전 확인 필수 — 외과 이외과 전문의 및 정형외과 최정형 전문의가 수술 전 혈소판 수치를 반드시 확인합니다.
- **혈소판 증가 (>400,000/uL):** 감염, 염증, 철결핍, 골수증식질환 감별.

**처방 진료과:** 전 진료과 (내과 김내과/윤내과, 외과 이외과, 소아과 박소아, 정형외과 최정형, 응급의학과 정응급, 산부인과 한산부, 신경과 송신경)

**사례:** 환자 김철수(1985년생, 남성, 혈액형 A+)가 피로감과 어지럼증을 호소하여 내과 김내과 전문의가 CBC를 시행했습니다. 혈색소 10.2g/dL로 빈혈이 확인되어 추가로 철 수치, 페리틴, 간기능검사(LFT)를 의뢰했습니다.

### 1-2. 간기능검사 (LFT, Liver Function Test)

**검사 개요**

간기능검사(LFT)는 간세포 손상, 담즙 정체, 간의 합성 기능을 평가하는 혈액검사입니다. 간질환 선별, 약물 투여 전후 간 기능 모니터링, 황달 원인 감별 등에 활용됩니다.

**검사 정보**

| 항목 | 내용 |
|------|------|
| 검사명 | LFT (Liver Function Test, 간기능검사) |
| 검체 | 정맥혈 5mL (SST 튜브, 노란색 뚜껑) |
| 금식 여부 | 8시간 금식 필수 (물은 소량 허용) |
| 검사 소요시간 | 약 2~3시간 |
| 결과 보고 | 당일 (오전 채혈 시 오후 보고) |
| 검사 장소 | 진단검사의학과 (지하 1층 채혈실) |
| 비용 | 건강보험 적용 시 약 8,000원 (본인부담금 기준) |

**정상 참고치**

| 검사 항목 | 정상 범위 | 단위 | 임상적 의의 |
|----------|----------|------|-----------|
| AST (GOT) | 0~40 | U/L | 간세포 손상 지표 |
| ALT (GPT) | 0~40 | U/L | 간세포 손상 특이적 지표 |
| ALP | 40~120 | U/L | 담즙 정체 지표 |
| GGT | 남 11~63 / 여 7~35 | U/L | 알코올성 간질환, 담즙 정체 |
| 총 빌리루빈 | 0.2~1.2 | mg/dL | 황달 지표 |
| 직접 빌리루빈 | 0~0.4 | mg/dL | 폐쇄성 황달 감별 |
| 알부민 | 3.5~5.0 | g/dL | 간 합성 기능 |
| 총 단백 | 6.0~8.3 | g/dL | 영양 상태, 간 기능 |
| PT (INR) | 0.9~1.2 | | 혈액 응고 기능, 간 합성 기능 |

**결과 해석 가이드**

- **AST/ALT 상승:** 간세포 손상 (급성 간염, 약물성 간 손상, 지방간, 알코올성 간질환). 오메프라졸 20mg 장기 복용 환자에서 간기능 추적 모니터링 목적으로 시행합니다.
- **ALP/GGT 상승:** 담즙 정체 (담석, 담관 폐쇄, 약물성).
- **알부민 감소:** 만성 간질환, 영양 불량.
- **빌리루빈 상승:** 황달 (간세포성, 폐쇄성, 용혈성 감별 필요).

**사전 준비 사항:**
1. 검사 전날 저녁 식사 후 8시간 금식 (물은 소량 허용)
2. 검사 당일 아침 약물 복용 여부는 담당의에게 확인 (오메프라졸 등 식전 복용 약물)
3. 음주는 검사 3일 전부터 금지 (GGT 수치 영향)
4. 격렬한 운동은 검사 전날 삼가 (AST 상승 가능)

**주요 처방 상황:** 내과 김내과 전문의의 소화기 환자 정기검사, 약물 투여 전 간기능 평가(아목시실린 500mg 장기 투여 시), 정대호(1965년생, 남성) 등 고령 환자의 건강 검진.

### 1-3. 혈당검사 (Blood Glucose Test)

**검사 개요**

혈당검사는 혈액 내 포도당 농도를 측정하여 당뇨병의 진단, 관리, 수술 전 평가에 사용됩니다. 공복 혈당, 식후 2시간 혈당, 당화혈색소(HbA1c) 검사를 포함합니다.

**검사 정보**

| 항목 | 내용 |
|------|------|
| 검사명 | 혈당검사 (Blood Glucose) |
| 검체 | 정맥혈 3mL (NaF 튜브, 회색 뚜껑) 또는 모세혈(현장검사) |
| 금식 여부 | 공복 혈당: 8시간 금식 필수 / 식후 혈당: 식사 후 2시간 |
| 검사 소요시간 | 현장검사: 즉시 / 정밀검사: 1~2시간 |
| 결과 보고 | 즉시(현장) ~ 당일 |
| 비용 | 건강보험 적용 시 약 2,000원 |

**정상 참고치**

| 검사 종류 | 정상 | 공복혈당장애/내당능장애 | 당뇨병 | 단위 |
|----------|------|---------------------|--------|------|
| 공복 혈당 | < 100 | 100~125 | >= 126 | mg/dL |
| 식후 2시간 혈당 | < 140 | 140~199 | >= 200 | mg/dL |
| HbA1c | < 5.7% | 5.7~6.4% | >= 6.5% | % |
| 수시 혈당 (증상 동반) | - | - | >= 200 | mg/dL |

**처방 상황:**
- 수술 전 평가: 외과 이외과 전문의 및 정형외과 최정형 전문의가 수술 전 혈당 확인
- 임신성 당뇨 선별: 산부인과 한산부 전문의가 한미영(1995년생, 여성) 등 임산부에게 임신 24~28주에 경구 당부하 검사 시행
- 당뇨 환자 추적: 정대호(1965년생, 남성) 등 당뇨 위험군 환자의 정기 혈당 모니터링
- 응급 상황: 정응급 전문의가 의식 변화 환자에게 즉각 현장 혈당검사 시행

**사전 준비 사항:**
1. 공복 혈당: 전날 저녁 식사 후 최소 8시간 금식
2. 금식 중 물 이외의 음료(커피, 주스 등) 섭취 금지
3. 검사 당일 아침 혈당약/인슐린 투여 여부는 담당의 확인
4. 식후 혈당: 식사 시작 시점부터 정확히 2시간 후 채혈

## 제2장. 소변검사

### 2-1. 소변검사 (Urinalysis)

**검사 개요**

소변검사는 신장 질환, 요로 감염, 당뇨병, 간질환 등을 선별하는 기본 검사입니다. 소변의 물리적 성상, 화학적 분석, 현미경적 분석을 포함합니다.

**검사 정보**

| 항목 | 내용 |
|------|------|
| 검사명 | 소변검사 (Urinalysis, U/A) |
| 검체 | 중간뇨 약 30mL (멸균 소변 컵) |
| 금식 여부 | 불필요 |
| 검사 소요시간 | 약 1~2시간 |
| 결과 보고 | 당일 (일반검사) / 배양검사: 2~3일 |
| 검사 장소 | 진단검사의학과 (지하 1층) 또는 병동 |
| 비용 | 건강보험 적용 시 약 2,500원 |

**정상 참고치**

| 항목 | 정상 | 이상 소견 |
|------|------|----------|
| 색상 | 연한 노란색~진한 노란색 | 혈뇨(적색), 빌리루빈뇨(갈색) |
| 비중 | 1.005~1.030 | 저비중: 희석뇨, 고비중: 탈수 |
| pH | 4.5~8.0 | 알칼리뇨: 요로감염 시사 |
| 단백 | 음성 | 양성: 신장 질환 |
| 당 | 음성 | 양성: 당뇨 (혈당 > 180mg/dL) |
| 잠혈 | 음성 | 양성: 혈뇨 (결석, 감염, 종양) |
| WBC | 0~5/HPF | 증가: 요로감염 |
| RBC | 0~3/HPF | 증가: 결석, 종양, 감염 |
| 세균 | 음성 | 양성: 요로감염 (배양검사 추가) |
| 아질산 | 음성 | 양성: 세균 감염 시사 |

**검체 채취 방법:**
1. 손을 비누로 깨끗이 씻습니다.
2. 소변을 처음 소량 버린 후, 중간 소변을 멸균 컵에 받습니다 (중간뇨 채취).
3. 컵 뚜껑을 닫고, 이름과 등록번호 라벨을 확인합니다.
4. 채취 후 30분 이내에 검사실로 제출합니다.
5. 소아 환자(박민준, 윤서준 등): 소변 채취백 부착 방법을 간호사에게 안내받습니다.

**처방 상황:** 전체 입원 환자 기본 검사, 산부인과 한산부 전문의의 임산부 산전검사, 요로감염 의심 시 아목시실린 500mg 처방 전 확인.

## 제3장. 영상검사

### 3-1. 흉부 X-ray (Chest X-ray)

**검사 개요**

흉부 X-ray는 폐, 심장, 흉곽, 종격동의 구조를 평가하는 가장 기본적인 영상검사입니다. 폐렴, 결핵, 기흉, 흉수, 심비대 등의 진단에 활용되며, 입원 및 수술 전 기본 검사로 시행됩니다.

**검사 정보**

| 항목 | 내용 |
|------|------|
| 검사명 | 흉부 X-ray (Chest PA/Lateral) |
| 검사 방법 | 직립 자세에서 후전방(PA) 및 측면(Lateral) 촬영 |
| 금식 여부 | 불필요 |
| 검사 소요시간 | 약 5~10분 |
| 결과 보고 | 영상: 즉시 확인 가능 / 판독문: 1~2시간 (응급: 30분) |
| 검사 장소 | 영상의학과 (지하 1층) 또는 이동촬영 (입원 환자) |
| 비용 | 건강보험 적용 시 약 6,000원 |
| 방사선 피폭량 | 약 0.02mSv (매우 낮음) |

**사전 준비 사항:**
1. 상의를 검사복으로 갈아입습니다.
2. 목걸이, 브래지어(와이어), 단추 등 금속 물질을 제거합니다.
3. 임산부(한미영 등): 반드시 임신 여부를 촬영 전 고지합니다. 납 앞치마 착용 또는 검사 보류를 결정합니다.
4. 소아 환자: 보호자 동행, 납 앞치마 차폐 적용.

**촬영 자세:**
- 직립 자세에서 X-ray판에 가슴을 밀착
- 양팔을 앞으로 모아 견갑골을 외측으로 이동
- 깊이 들이마신 상태에서 숨 참기 (촬영 신호에 맞춰)

**판독 소견 주요 항목:**
- 폐야: 폐렴, 결핵, 종괴, 기흉 유무
- 심장: 심비대(심흉비 > 50%), 심낭삼출
- 종격동: 종격동 확대, 림프절 비대
- 흉막: 흉수, 흉막 비후
- 골격: 늑골 골절, 척추 이상

**주요 처방 의료진:**
- 윤내과 전문의: 만성 기침 환자(정대호 등)의 호흡기 질환 감별
- 정응급 전문의: 응급 환자 초기 평가
- 이외과/최정형 전문의: 수술 전 기본 검사
- 한산부 전문의: 원칙적으로 임산부에게 시행하지 않으나, 필요 시 복부 차폐 후 시행

---

### 3-2. 심전도 (ECG, Electrocardiogram)

**검사 개요**

심전도(ECG)는 심장의 전기적 활동을 기록하여 부정맥, 심근 허혈, 심근경색, 전해질 이상 등을 진단하는 검사입니다. 비침습적이며 통증이 없는 검사로, 수술 전 평가 및 흉통 환자의 기본 검사입니다.

**검사 정보**

| 항목 | 내용 |
|------|------|
| 검사명 | 심전도 (12-lead ECG) |
| 검사 방법 | 흉부 6개, 사지 4개 전극 부착 후 기록 |
| 금식 여부 | 불필요 |
| 검사 소요시간 | 약 5~10분 |
| 결과 보고 | 즉시 (자동 판독) / 전문의 판독: 1시간 이내 |
| 검사 장소 | 진단검사의학과 (지하 1층) 또는 병동/응급센터 |
| 비용 | 건강보험 적용 시 약 8,000원 |

**정상 심전도 기준:**

| 항목 | 정상 범위 |
|------|----------|
| 심박수 | 60~100회/분 |
| P파 | 양성 (II, III, aVF), 폭 < 0.12초 |
| PR 간격 | 0.12~0.20초 |
| QRS폭 | < 0.12초 |
| QT 간격 (보정) | 남 < 0.44초, 여 < 0.46초 |
| ST 분절 | 기준선 |
| T파 | 양성 (대부분 유도) |

**검사 시 주의사항:**
1. 금속 장신구 제거
2. 상의 탈의 (검사복 착용)
3. 검사 중 움직이지 않기 (근전도 잡음 방지)
4. 시계, 휴대전화 등 전자기기 거리 두기

**주요 처방 상황:**
- 수술 전 평가: 40세 이상 환자 — 최수아(1978년생), 정대호(1965년생) 등이 수술 예정 시 필수
- 흉통 감별: 응급의학과 정응급 전문의가 내원 즉시 시행
- 약물 투여 전: 수마트립탄 50mg(두통약) 처방 전 송신경 전문의가 심전도 정상 확인
- 정기 검진: 고혈압, 당뇨 등 심혈관 위험인자 보유 환자

### 3-3. CT 촬영 (Computed Tomography)

**검사 개요**

CT(컴퓨터단층촬영)는 X-ray와 컴퓨터를 이용하여 신체 단면 영상을 얻는 고해상도 영상검사입니다. 종양, 골절, 출혈, 농양, 혈관 질환 등의 정밀 진단에 활용됩니다. 조영제를 사용하는 조영증강 CT와 단순 CT로 구분됩니다.

**검사 정보**

| 항목 | 내용 |
|------|------|
| 검사명 | CT 촬영 (Computed Tomography) |
| 검사 종류 | 뇌 CT, 흉부 CT, 복부/골반 CT, 척추 CT, 사지 CT |
| 검사 소요시간 | 약 10~30분 (부위 및 조영 여부에 따라) |
| 금식 여부 | 조영증강 CT: 4시간 금식 / 단순 CT: 불필요 |
| 결과 보고 | 영상: 즉시 / 판독문: 2~4시간 (응급: 30분~1시간) |
| 검사 장소 | 영상의학과 CT실 (지하 1층) |
| 비용 | 건강보험 적용 시 약 80,000~250,000원 (부위별 상이) |
| 방사선 피폭량 | 부위별 2~20mSv |

**조영제 관련 안내:**

| 항목 | 내용 |
|------|------|
| 조영제 종류 | 요오드계 비이온성 조영제 |
| 투여 경로 | 정맥주사 |
| 주요 부작용 | 오심(2%), 두드러기(1%), 드물게 아나필락시스(0.01%) |
| 금기 | 요오드 과민반응, 중증 신부전(eGFR < 30), 갑상선 기능항진증 |
| 당뇨약 주의 | 메트포르민 복용 환자: CT 당일 및 48시간 후까지 메트포르민 중단 |
| 신기능 확인 | 조영 CT 전 혈청 크레아티닌/eGFR 확인 필수 |

**사전 준비 사항:**
1. 조영증강 CT: 검사 4시간 전부터 금식 (물은 소량 허용)
2. 이전 조영제 부작용 경험이 있으면 반드시 고지
3. 알레르기 체질인 경우 사전 투약(스테로이드, 항히스타민제) 시행
4. 임산부: 원칙적으로 CT 촬영 지양. 불가피한 경우 산부인과 한산부 전문의 협의 후 복부 차폐
5. 소아(박민준, 윤서준): 저선량 CT 프로토콜 적용, 진정제 필요 시 소아과 박소아 전문의 협의

**검사 후 안내:**
1. 조영제 배출을 위해 검사 후 24시간 동안 충분한 수분 섭취
2. 주사 부위 통증, 부종, 발적 시 의료진에게 즉시 알림
3. 지연성 부작용(두드러기, 발진 등): 검사 후 수 시간~수일 내 발생 가능

**주요 처방 상황:**
- 응급의학과 정응급 전문의: 복통(이영희 사례 — 복부 CT로 급성 충수염 진단), 두부 외상, 뇌졸중 의심
- 내과 윤내과 전문의: 만성 기침 환자 흉부 CT (흉부 X-ray에서 이상 소견 시)
- 신경과 송신경 전문의: 두통 환자 뇌 CT (뇌출혈, 종양 감별)
- 외과 이외과 전문의: 수술 전 병변 정밀 평가
