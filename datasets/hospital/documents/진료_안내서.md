# 진료 안내서

## 외래 진료 절차

### 1단계: 접수
- **초진**: 1층 원무과에서 접수 (신분증, 건강보험증 지참)
- **재진**: 무인 접수기 또는 모바일 앱으로 접수 가능

### 2단계: 진료
각 진료과에서 순서대로 진료합니다.
- 대기 현황은 전광판 또는 모바일 앱에서 확인
- 예약 환자 우선 진료

### 3단계: 검사 (필요 시)
| 검사 종류 | 위치 | 소요시간 |
|-----------|------|----------|
| 혈액검사 | 1층 채혈실 | 결과 2~3시간 |
| X-ray | 지하1층 영상의학과 | 즉시 |
| CT/MRI | 지하1층 영상의학과 | 결과 1~2일 |
| 초음파 | 각 진료과 | 즉시 |

### 4단계: 수납 및 처방
- 진료 후 1층 수납창구 또는 무인 수납기에서 수납
- 처방전은 원내 또는 원외 약국에서 조제

## 진료과 안내

- **내과** (3층): 소화기, 호흡기, 순환기, 내분비
- **외과** (4층): 일반외과, 유방, 갑상선
- **소아과** (2층): 소아청소년과
- **정형외과** (5층): 관절, 척추, 스포츠의학
- **응급의학과** (1층): 24시간 운영
- **산부인과** (6층): 산과, 부인과
- **신경과** (7층): 두통, 어지러움, 치매
