## 1. 환영 인사

코딩 부트캠프에 입학하신 것을 진심으로 환영합니다. 본 핸드북은 수강 기간 동안 알아야 할 모든 규정과 절차를 담고 있습니다. 입학일 기준으로 본 핸드북의 모든 내용에 동의한 것으로 간주되며, 변경 사항은 공지 채널을 통해 사전 안내됩니다.

현재 운영 중인 캠퍼스는 강남캠퍼스(서울시 강남구 테헤란로 212), 판교캠퍼스(경기도 성남시 분당구 판교로 228), 부산캠퍼스(부산시 해운대구 센텀중앙로 55) 3개소이며, 각 캠퍼스별 세부 운영 시간은 캠퍼스 운영 가이드를 참고하시기 바랍니다.

## 2. 등록 및 입학 절차

### 2.1 수강 등록 프로세스

1. 온라인 지원서 제출 (홈페이지)
2. 코딩 테스트 또는 사전 과제 제출 (과정별 상이)
3. 1:1 면접 (온라인 또는 대면, 30분)
4. 합격 통보 (지원 후 5영업일 이내)
5. 수강료 납부 및 학습 계약서 서명
6. OT(오리엔테이션) 참석 (개강 1주 전)
7. 학습 환경 세팅 가이드 수령 (노트북, 개발 도구 설치)

### 2.2 수강료 및 환불 정책

환불 기준:

- 수업 1/3 경과 전: 수강료의 2/3 환불
- 수업 1/2 경과 전: 수강료의 1/2 환불
- 수업 1/2 경과 후: 환불 불가

### 2.3 오리엔테이션

개강 1주 전 의무 참석이며, 다음 내용을 안내합니다:

- Slack 워크스페이스 및 GitHub Organization 초대
- 학습 관리 시스템(LMS) 사용법 안내
- 담당 강사 및 멘토 소개
- 팀 구성 및 아이스브레이킹

## 3. 출석 정책

### 3.1 수업 시간

| 구분 | 시간 | 비고 |
|------|------|------|
| 오전 수업 | 09:30 ~ 12:30 | 강의 및 실습 |
| 점심시간 | 12:30 ~ 13:30 | |
| 오후 수업 | 13:30 ~ 17:30 | 실습 및 팀 활동 |
| 자율 학습 | 17:30 ~ 21:00 | 선택 (강사 질의 가능) |

### 3.2 출석 인정 기준

- 수업 시작 10분 이내 입실: 정상 출석
- 수업 시작 후 10~30분: 지각 (3회 지각 = 결석 1회)
- 수업 시작 후 30분 초과: 결석 처리
- 조퇴: 오후 15:00 이전 퇴실 시 결석 0.5회 처리

### 3.3 출석률 기준

- 80% 이상: 정상 수료 가능
- 70~79%: 경고 1회 부여, 보충 과제 필수
- 70% 미만: 수료 불가 (퇴소 처리)
- 공가 사유: 병원 진단서, 직계가족 경조사, 취업 면접 (사전 신청 필수)

### 3.4 출석 체크 방법

각 캠퍼스 입구의 QR 코드 체크인 시스템을 통해 자동 기록됩니다. QR 체크인이 불가한 경우 교육운영팀에 직접 연락하여 수동 처리를 요청할 수 있습니다.

## 4. 과제 제출 규정

### 4.1 제출 방법

모든 과제는 GitHub를 통해 제출합니다:
1. 과정별 Organization 내 개인 레포지토리에 push
2. 제출 기한까지 Pull Request 생성
3. PR 제목 형식: `[Week-XX] 과제명 - 본인이름`
4. PR 본문에 셀프 체크리스트 작성

### 4.2 제출 기한

- 일반 과제: 해당 주차 금요일 23:59까지
- 프로젝트: 발표일 전일 23:59까지
- 지각 제출: 1일당 10% 감점 (최대 3일, 이후 0점 처리)

### 4.3 표절 정책

- 코드 유사도 검사 도구(MOSS)를 활용하여 자동 검사
- 30% 이상 유사도 적발 시: 해당 과제 0점 + 경고 1회
- 2회 이상 적발 시: 퇴소 처리
- 오픈소스 활용 시 반드시 출처 명시 및 라이선스 준수

### 4.4 코드 품질 기준

모든 제출 코드는 다음 기준을 충족해야 합니다:
- ESLint/Prettier (프론트엔드) 또는 PEP8 (Python) 준수
- 의미 있는 변수명 및 함수명 사용
- 주요 로직에 대한 주석 작성
- README.md에 실행 방법 명시
- 테스트 코드 최소 1개 이상 포함 (중간 과제부터)

## 5. 팀 프로젝트 가이드라인

### 5.1 팀 구성

- 풀스택 웹개발 부트캠프: 4인 1팀 (총 7~8팀)
- AI/ML 엔지니어링: 3~4인 1팀 (총 5~6팀)
- 클라우드 DevOps: 4인 1팀 (총 5팀)
- 백엔드 Java Spring: 4~5인 1팀 (총 6~7팀)

팀 구성은 강사가 기술 수준 균형을 고려하여 배정하며, 수강생 간 희망 사항을 최대한 반영합니다.

### 5.2 역할 분담

각 팀은 다음 역할을 반드시 지정해야 합니다:
- 팀장 (PM): 일정 관리, 스프린트 회의 진행
- 기술 리드: 아키텍처 결정, 코드 리뷰 주관
- 발표자: 데모데이 발표 담당
- QA: 테스트 및 품질 관리

### 5.3 협업 도구

| 도구 | 용도 | 필수 여부 |
|------|------|----------|
| GitHub | 코드 관리, PR 기반 협업 | 필수 |
| Slack | 실시간 커뮤니케이션 | 필수 |
| Notion | 회의록, 문서화 | 권장 |
| Figma | UI/UX 디자인 | 프론트엔드 과정 필수 |
| Jira/Linear | 이슈 트래킹 | 권장 |

### 5.4 스프린트 운영

- 1주 단위 스프린트 권장
- 매일 오전 09:30 데일리 스탠드업 (15분)
- 금요일 오후 스프린트 회고
- 스프린트별 결과물을 강사에게 중간 점검 받기

### 5.5 팀 갈등 해결

팀 내 갈등 발생 시 다음 단계를 따릅니다:
1. 팀 내 자체 해결 시도 (24시간)
2. 담당 강사에게 중재 요청
3. 교육운영팀 개입 (필요 시 팀 재편성)

## 6. 생활 규정 및 행동 강령

### 6.1 캠퍼스 이용 규칙

- 음식물 반입은 휴게실에서만 허용 (강의실 내 음료만 가능)
- 공용 장비 사용 후 원위치 (모니터, 키보드, 마우스)
- 개인 물품 보관은 지정 사물함 이용 (분실 시 본인 책임)
- 퇴실 시 자리 정리 및 전원 차단 확인

### 6.2 행동 강령

본 부트캠프는 다음 행위를 엄격히 금지합니다:
- 성별, 나이, 출신, 장애 등에 기반한 차별 및 혐오 발언
- 타인의 학습을 방해하는 행위 (소음, 지속적 사담)
- 강사 또는 동료에 대한 언어적/물리적 폭력
- 무단 촬영 및 녹음
- 캠퍼스 내 음주 및 흡연 (지정 흡연구역 제외)

위반 시 1차 경고, 2차 퇴소 조치를 원칙으로 합니다.

### 6.3 개인정보 보호

- 수강생 간 연락처 공유는 본인 동의 하에만 가능
- 팀 프로젝트 중 수집한 데이터는 과정 종료 후 즉시 삭제
- SNS에 동료 사진 게시 시 반드시 사전 동의 필요

### 7.1 수료 조건

다음 조건을 모두 충족해야 수료증이 발급됩니다:
1. 출석률 80% 이상
2. 전체 평가 점수 65점 이상 (C등급 이상)
3. 필수 과제 100% 제출 (지각 제출 포함)
4. 행동 강령 위반으로 인한 퇴소 처분 없음

### 7.2 수료 혜택

- 공식 수료증 발급 (디지털 배지 포함)

- 향후 과정 20% 할인 (1회)
