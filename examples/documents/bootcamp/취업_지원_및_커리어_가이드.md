## 1. 취업지원팀 소개

안녕하세요, 취업지원팀 커리어 코치 한소영입니다. 저희 팀은 수강생 여러분이 부트캠프 수료 후 원하는 기업에 성공적으로 취업할 수 있도록 체계적인 지원 프로그램을 운영하고 있습니다.

취업지원팀은 다음과 같은 서비스를 제공합니다:
- 1:1 커리어 상담 및 진로 설계
- 이력서/포트폴리오 첨삭
- 모의 면접 (기술 면접 + 인성 면접)
- 파트너 기업 채용 연계
- 네트워킹 이벤트 기획 및 운영
- 수료 후 3개월간 사후 관리

## 3. 이력서 작성 가이드

### 3.1 이력서 구성 요소

1. 기본 정보 (이름, 연락처, GitHub, LinkedIn, 블로그)
2. 자기소개 (3줄 이내, 핵심 기술 + 강점)
3. 기술 스택 (숙련도별 분류)
4. 프로젝트 경험 (최신순 3~5개)
5. 교육 이력
6. 자격증 및 수상
7. 기타 활동 (오픈소스 기여, 스터디 등)

### 3.2 프로젝트 기술 방법 (STAR 기법)

- Situation: 프로젝트 배경 및 목표
- Task: 본인이 맡은 역할
- Action: 구체적으로 수행한 기술적 작업
- Result: 정량적 성과 (성능 개선률, 사용자 수 등)

### 3.3 과정별 이력서 포인트

#### 풀스택 웹개발 부트캠프 수료생
- React + Node.js 풀스택 개발 역량 강조
- 팀 프로젝트에서의 협업 경험 (Git Flow, 코드 리뷰)
- 배포 경험 (AWS, Docker)
- 참고 수강생: 김지원(1998), 이서준(1999), 박민지(1997)은 팀 프로젝트에서 각각 PM, 백엔드 리드, 프론트엔드 리드를 담당하여 우수한 포트폴리오 확보

#### 데이터 사이언스 입문 수료생
- Python 데이터 분석 파이프라인 구축 역량
- 공공데이터/실제 데이터를 활용한 분석 프로젝트
- 시각화 및 인사이트 도출 능력
- 강예서(1999)는 통계학 전공을 살려 A/B 테스트 설계 프로젝트로 차별화

#### AI/ML 엔지니어링 수료생
- 논문 구현 및 재현 실험 경험
- MLOps 파이프라인 구축 (모델 학습~서빙)
- 최신 LLM 파인튜닝 경험
- 정하윤(2000)과 최도현(1996)은 캡스톤 프로젝트에서 실시간 추천 시스템 구축

#### 프론트엔드 심화과정 수료생
- TypeScript 기반 타입 안전 개발
- Next.js SSR/SSG 성능 최적화 경험
- 디자인 시스템 구축 또는 기여 경험
- 조은우(1997)는 기존 React 경력에 TypeScript+Next.js를 더해 시니어급 포지션 지원 가능

#### 클라우드 DevOps 수료생
- AWS 인프라 설계 및 운영 경험
- Kubernetes 클러스터 구축/운영
- CI/CD 파이프라인 자동화
- 한수빈(2001)은 보안 전공을 살려 DevSecOps 포지션 차별화 전략 수립

#### 백엔드 Java Spring 수료생
- Spring Boot + JPA 기반 REST API 설계/구현
- 대용량 트래픽 처리 경험 (캐싱, 비동기)
- MSA 설계 및 구현 경험
- 신유나(2000)는 부산캠퍼스에서 팀 프로젝트 PM으로 리더십 경험 확보

### 3.4 이력서 첨삭 프로세스

1. 초안 작성 후 Notion 제출
2. 한소영 코치 1차 피드백 (2영업일 이내)
