## 제1장. 캠퍼스 개요

### 1.1 캠퍼스 배치

한국미래대학교 캠퍼스는 총 면적 85,000평방미터 부지에 5개 주요 건물과 부속 시설로 구성되어 있습니다. 각 건물은 학과 특성에 맞게 설계되었으며, 건물 간 이동은 도보 기준 최대 10분 이내로 접근이 가능합니다.

| 건물명 | 연면적 | 층수 | 준공연도 | 주요 입주 학과 |
|--------|--------|------|----------|---------------|
| 공학관 | 8,200평방미터 | 지하1층~지상5층 | 2005 | 컴퓨터공학과 |
| 경영관 | 6,500평방미터 | 지하1층~지상4층 | 2001 | 경영학과 |
| 예술관 | 5,800평방미터 | 지하1층~지상4층 | 2010 | 디자인학과 |
| 자연과학관 | 7,100평방미터 | 지하1층~지상5층 | 2003 | 수학과, 물리학과, 화학과 |
| 인문관 | 6,000평방미터 | 지하1층~지상4층 | 2004 | 영어영문학과, 국어국문학과, 철학과 |

### 1.2 건물 운영 시간

| 구분 | 평일 | 토요일 | 일요일/공휴일 |
|------|------|--------|--------------|
| 건물 개방 | 06:00~22:00 | 08:00~18:00 | 폐쇄 (특별 허가 시 개방) |
| 강의실 이용 | 08:00~21:00 | 09:00~17:00 | 폐쇄 |
| 실습실/스튜디오 | 08:00~22:00 | 09:00~18:00 | 폐쇄 |
| 교수 연구실 | 24시간 (카드키) | 24시간 | 24시간 |

### 1.3 출입 관리

1. 모든 건물은 학생증/교직원증 기반 전자출입 시스템으로 운영됩니다.
2. 야간(18:00 이후) 출입 시 1층 경비실에서 출입 기록부 작성이 필요합니다.
3. 외부 방문객은 정문 안내데스크에서 방문증을 발급받아야 합니다.
4. 실습실 및 특수 시설은 사전 예약 후 출입이 가능합니다.

## 제3장. 경영관 (Business Hall)

### 3.1 건물 개요

경영관은 2001년 준공된 경영학과 전용 건물로, 학과장 이교수의 학과 사무실이 2층에 위치합니다. 실무 중심 교육을 위한 다양한 시설을 갖추고 있습니다.

### 3.2 층별 안내

| 층 | 시설 | 주요 용도 |
|----|------|-----------|
| B1 | 주차장 (50면), 기계실 | 주차, 설비 |
| 1층 | 102호 대강의실(80명), 로비, 학생 라운지 | 대형 강의 |
| 2층 | 학과 사무실, 팀 프로젝트실 3개 (각 12명), 모의 주식거래실 | 행정, 실습 |
| 3층 | 301~306호 교수 연구실, 경영 시뮬레이션 랩 | 연구, 실습 |
| 4층 | 세미나실 2개 (각 30명), 취업 지원 센터 | 세미나, 취업 |

### 3.3 경영관 102호 (대강의실)

| 항목 | 사양 |
|------|------|
| 수용인원 | 80명 |
| 면적 | 200평방미터 |
| 좌석 배치 | 계단식 고정좌석 80석 (4블록 x 20석) |
| 영상 장비 | 빔 프로젝터 2대 (6000lm), 전동 스크린 2매 (180인치), 대형 LED 디스플레이 1대 (85인치) |
| 음향 장비 | 천장 매립형 스피커 6개, 무선 마이크 3대, 믹싱 콘솔 |
| 녹화 장비 | PTZ 카메라 2대, 강의 자동 녹화 시스템 (LMS 자동 업로드) |
| 기타 장비 | 전자칠판 1대, 실시간 투표/퀴즈 시스템 (Mentimeter 연동) |
| 냉난방 | 중앙 공조 시스템, 개별 제어 가능 |
| 주요 수업 | BUS101 경영학원론 (박경영 교수) |

경영관 102호는 본교 최대 규모의 강의실로, 80명 동시 수용이 가능합니다. 박경영 정교수의 경영학원론(BUS101) 강의가 이 강의실에서 진행되며, 박민수(경영 4학년)가 조교로 강의 운영을 보조하고 있습니다. 윤준호(경영 3학년)를 포함한 다수의 경영학과 학생이 이 강의실을 이용합니다.

### 3.4 경영 시뮬레이션 랩

경영관 3층에 위치한 경영 시뮬레이션 랩은 기업 경영 시뮬레이션 소프트웨어(Capsim, Markstrat)를 활용한 실습 공간입니다. PC 20대와 대형 디스플레이 4대가 설치되어 있으며, 팀 단위 경영 의사결정 시뮬레이션을 수행합니다.

## 제5장. 자연과학관 (Natural Science Hall)

### 5.1 건물 개요

자연과학관은 2003년 준공되어 수학과, 물리학과, 화학과가 입주해 있습니다. 수학과 학과장 최교수의 사무실이 2층에 위치합니다.

### 5.2 층별 안내

| 층 | 시설 | 주요 용도 |
|----|------|-----------|
| B1 | 물리/화학 실험실, 시약 보관실 | 자연과학 실험 |
| 1층 | 수학 전공 도서실, 자연과학 세미나실 (50명) | 열람, 세미나 |
| 2층 | 201~204호 교수 연구실, 학과 사무실 (수학과) | 연구, 행정 |
| 3층 | 수치 연산실, 통계 실습실 | 실습 |
| 4층 | 대학원 연구실, 세미나실 | 연구 |
| 5층 | 천문 관측실, 옥상 정원 | 관측, 휴식 |

### 5.3 수학 전공 도서실 (1층)

면적 120평방미터, 열람석 40석, 수학 전공 서적 5,000여 권, 해외 학술지 30종을 보유하고 있습니다. 한서연(수학 2학년, GPA 4.3)이 매주 화요일 16:00~18:00에 미적분학(MATH101) 보충 튜터링을 이 도서실 세미나 코너에서 진행하고 있습니다.

### 5.4 수치 연산실 (3층)

PC 20대(MATLAB R2025b, Mathematica 14, Python 3.12, R 4.4 설치), 대형 디스플레이 2대를 갖추고 있으며, 수학과 및 공학 계열 학생의 수치 해석 실습에 사용됩니다. 정수학 정교수의 미적분학(MATH101) 보충 수업 및 수치해석 과목 실습이 이 연산실에서 진행됩니다.

## 제6장. 인문관 (Humanities Hall)

### 6.1 건물 개요

인문관은 2004년 준공되어 영어영문학과, 국어국문학과, 철학과가 입주해 있습니다. 영어영문학과 학과장 정교수의 사무실이 3층에 위치합니다.

### 6.2 층별 안내

| 층 | 시설 | 주요 용도 |
|----|------|-----------|
| B1 | 소극장 (100석), 다목적 홀 | 공연, 행사 |
| 1층 | 영어 원서 도서관, 영어 카페 (English Zone) | 열람, 회화 연습 |
| 2층 | 어학 실습실 2개 (각 35명), 동시통역 부스 4개 | 어학 실습 |
| 3층 | 301~306호 교수 연구실, 학과 사무실 | 연구, 행정 |
| 4층 | 세미나실 2개 (각 30명), 글쓰기 센터 | 세미나, 글쓰기 |

### 6.3 어학 실습실 (2층)

| 항목 | 사양 |
|------|------|
| 수용인원 | 각 35명 (2개실) |
| 장비 | 개인별 헤드셋+마이크 35세트, PC 35대, 어학 학습 소프트웨어 (CALL 시스템) |
| 소프트웨어 | EnglishCentral, Rosetta Stone, TOEIC 대비 프로그램 |
| 부대시설 | 교수용 모니터링 시스템 (학생 PC 화면 실시간 확인) |
| 주요 수업 | ENG201 비즈니스 영어 (한영어 부교수) |

한영어 부교수의 비즈니스 영어(ENG201) 실습 수업이 매주 화요일 오후에 이 실습실에서 진행됩니다. 송미래(영문 1학년)는 1층 영어 카페(English Zone)를 매일 이용하며 영어 몰입 연습을 하고 있습니다.

### 6.4 동시통역 부스

인문관 2층에 위치한 동시통역 부스 4개는 방음 처리된 개별 부스로, 통번역 트랙 학생의 실습에 사용됩니다. 각 부스는 2인용이며, 전문 통역 장비(Bosch Integrus 시스템)가 설치되어 있습니다.

### 6.5 영어 카페 (English Zone)

인문관 1층에 위치한 영어 카페는 영어 전용 공간으로, 입장 시 한국어 사용을 자제하는 규칙이 적용됩니다. 원어민 튜터 2명이 상주하며(평일 10:00~16:00), 자유 회화, 발음 교정, 영작문 첨삭 서비스를 제공합니다. 커피/음료 자판기와 간단한 다과가 제공되며, 영어 원서 소장 코너(1,200권)가 마련되어 있습니다.
