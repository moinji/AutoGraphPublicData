# 병동 운영 및 환자 안전 관리

**서울중앙병원 병동 운영 및 환자 안전 관리 매뉴얼**

발행일: 2026년 3월 1일 | 개정판: 제8판 | 발행처: 서울중앙병원 간호부 / 환자안전팀

---

## 제1장. 총칙

### 1-1. 목적

본 매뉴얼은 서울중앙병원 전 병동의 운영 기준, 인력 배치, 감염 관리, 환자 안전 프로토콜을 수립하여 안전하고 효율적인 입원 환경을 제공하는 것을 목적으로 합니다.

### 1-2. 적용 범위

본 매뉴얼은 서울중앙병원의 6개 병동(내과 일반병동, 외과 병동, 소아 병동, 정형외과 병동, 응급 관찰실, 산부인과 병동)에 근무하는 전 의료진 및 지원 인력에게 적용됩니다.

### 1-3. 관련 법규

- 의료법 제36조 (의료기관의 시설 기준)
- 의료법 제47조 (의료기관 인증)
- 환자안전법 제2조 (환자안전사고 정의)
- 감염병의 예방 및 관리에 관한 법률 제36조 (의료기관 감염 관리)

## 제2장. 병동별 운영 현황

### 2-1. 내과 일반병동 (3층)

| 항목 | 내용 |
|------|------|
| 병동명 | 내과 일반병동 |
| 위치 | 본관 3층 |
| 병상 수 | 30병상 |
| 병실 구성 | 6인실 3실, 4인실 2실, 2인실 2실, 1인실 2실 |
| 담당 전문의 | 김내과 (소화기내과, MD-2010-001), 윤내과 (호흡기내과) |
| 수간호사 | 1명 |
| 간호 인력 | 간호사 8명 (3교대), 간호조무사 3명 |
| 간호사 대 환자 비율 | 주간 1:5, 야간 1:10 |
| 주요 입원 환자 | 소화기 질환, 호흡기 질환, 순환기 질환, 내분비 질환 |
| 상비 약품 | 오메프라졸 20mg(250원/정), 덱스트로메토르판(기침약), 세티리진 10mg(항히스타민) |
| 주요 검사 장비 | 이동형 심전도(ECG) 기기, 혈당 측정기, 산소포화도 측정기 |

**운영 특이사항:**
- 소화기내과 환자의 경우 김내과 전문의(MD-2010-001)가 오메프라졸 20mg 기반 위산 억제 요법을 주로 시행하며, 내시경 검사 전후 환자의 금식 관리를 병동에서 담당합니다.
- 호흡기내과 환자의 경우 윤내과 전문의가 덱스트로메토르판 투약 및 흉부 X-ray 추적을 관리합니다.
- 김철수(1985년생, 남성, 혈액형 A+) 등 소화기 환자의 내시경 전 준비(금식, 장세척)를 병동 간호사가 담당합니다.
- 정대호(1965년생, 남성) 등 고령 환자에 대해 낙상 위험 평가를 입원 시 시행합니다.

### 2-2. 외과 병동 (4층)

| 항목 | 내용 |
|------|------|
| 병동명 | 외과 병동 |
| 위치 | 본관 4층 |
| 병상 수 | 25병상 |
| 병실 구성 | 6인실 2실, 4인실 2실, 2인실 2실, 1인실 1실 |
| 담당 전문의 | 이외과 (일반외과) |
| 수간호사 | 1명 |
| 간호 인력 | 간호사 7명 (3교대), 간호조무사 2명 |
| 간호사 대 환자 비율 | 주간 1:5, 야간 1:8 |
| 주요 입원 환자 | 수술 전후 환자 (담낭절제, 충수절제, 탈장수술, 유방수술) |
| 상비 약품 | 아목시실린 500mg(300원/캡슐, 수술 후 감염 예방), 이부프로펜 400mg(수술 후 진통) |
| 주요 장비 | 흡인기, 수술 후 드레인 관리 장비, PCA(자가통증조절) 펌프 |

**운영 특이사항:**
- 이외과 전문의의 수술 후 환자는 회복실에서 병동으로 이송되며, 첫 24시간은 2시간 간격 활력징후 측정을 시행합니다.
- 수술 후 감염 예방을 위해 아목시실린 500mg을 3~5일간 투여하며, 통증 관리를 위해 이부프로펜 400mg을 식후 처방합니다.
- 이영희(1990년생, 여성, 혈액형 B+)가 복강경 충수절제술 후 외과 병동에 입원한 사례에서, 수술 당일부터 조기 보행을 격려하고 3일 후 퇴원했습니다.
- 수술 전 환자에 대해 CBC, 심전도(ECG), 흉부 X-ray, 혈당검사를 필수로 시행합니다.
- 수술 부위 감염(SSI) 모니터링: 수술 후 30일간 추적 관찰. 2025년 기준 SSI 발생률 2.1%.

### 2-3. 소아 병동 (2층)

| 항목 | 내용 |
|------|------|
| 병동명 | 소아 병동 |
| 위치 | 본관 2층 |
| 병상 수 | 20병상 |
| 병실 구성 | 4인실 3실, 2인실 2실, 1인실 4실 (보호자 동반) |
| 담당 전문의 | 박소아 (소아청소년과) |
| 수간호사 | 1명 |
| 간호 인력 | 간호사 7명 (3교대), 간호조무사 2명 |
| 간호사 대 환자 비율 | 주간 1:4, 야간 1:7 |
| 주요 입원 환자 | 소아 감염, 소아 호흡기 질환, 탈수, 소아 수술 후 관리 |
| 상비 약품 | 아세트아미노펜 시럽(해열제), 아목시실린 현탁액(항생제), 세티리진 시럽(항히스타민) |
| 특수 장비 | 소아 전용 활력징후 모니터, 소아 수액세트, 체중 측정기 |

**운영 특이사항:**
- 보호자 1인 24시간 동반 입원이 가능하며, 보호자용 간이침대를 제공합니다.
- 소아 전용 병동 환경: 벽면 동물 벽화, 놀이 공간(플레이룸) 운영, 아동심리사 주 2회 방문.
- 박소아 전문의가 박민준(2018년생, 남아) 및 윤서준(2020년생, 남아) 등 소아 환자를 관리하며, 체중 기반 약물 용량 산정을 모든 투약 시 시행합니다.
- 아세트아미노펜 시럽 투약 시 체중별 용량표를 병동에 비치하고, 투약 전 체중 재측정을 원칙으로 합니다.
- 소아 환자 팔찌에 알레르기 정보 및 체중을 추가 기재합니다.
- 예방접종 미완료 소아의 격리 여부를 입원 시 확인합니다.

**낙상 예방 (소아 특이사항):**
- 침대 난간 항시 올림
- 2세 미만 영아: 침대 그물망 설치
- 보행 가능 소아: 미끄럼방지 슬리퍼 제공
- 놀이 공간 바닥 완충재 설치

### 2-4. 정형외과 병동 (5층)

| 항목 | 내용 |
|------|------|
| 병동명 | 정형외과 병동 |
| 위치 | 본관 5층 |
| 병상 수 | 20병상 |
| 병실 구성 | 6인실 2실, 4인실 1실, 2인실 1실, 1인실 2실 |
| 담당 전문의 | 최정형 (관절) |
| 수간호사 | 1명 |
| 간호 인력 | 간호사 6명 (3교대), 간호조무사 2명 |
| 간호사 대 환자 비율 | 주간 1:5, 야간 1:10 |
| 주요 입원 환자 | 인공관절 수술, 골절 수술, 십자인대 재건술, 회전근개 수술 |
| 상비 약품 | 이부프로펜 400mg(진통제), 아목시실린 500mg(수술 후 항생제) |
| 특수 장비 | CPM(지속적수동운동) 기계, 냉각치료기, 보행 보조기, 목발 |

**운영 특이사항:**
- 최정형 전문의의 인공관절 수술 환자는 수술 후 1일째부터 CPM 기계를 이용한 관절 운동을 시작합니다.
- 최수아(1978년생, 여성)가 무릎 인공관절 수술 후 정형외과 병동에 입원한 사례에서, 이부프로펜 400mg 기반 통증 관리 프로토콜과 단계적 재활을 적용하여 7일 만에 퇴원했습니다.
- 수술 후 심부정맥혈전증(DVT) 예방: 탄력스타킹 착용, 조기 보행, 필요 시 항응고제 투여.
- 석고 고정/보조기 착용 환자의 피부 상태를 4시간마다 확인합니다.
- 수술 전 혈당검사, CBC, 흉부 X-ray를 필수로 시행합니다.

**낙상 예방 (정형외과 특이사항):**
- 수술 후 환자의 첫 보행은 반드시 간호사 동행
- 보행 보조기(워커, 목발) 사용법 교육 필수
- 미끄럼방지 매트 병실 및 화장실에 설치
- 야간 조명 상시 유지
- 낙상 고위험 환자 침대: 높이 최하단 고정, 침대 알람 설정

### 2-5. 응급 관찰실 (1층)

| 항목 | 내용 |
|------|------|
| 병동명 | 응급 관찰실 |
| 위치 | 본관 1층 (응급센터 내) |
| 병상 수 | 10병상 |
| 병실 구성 | 개방형 관찰실 8병상, 격리실 2실 |
| 담당 전문의 | 정응급 (응급의학) |
| 간호 인력 | 간호사 6명 (3교대), 응급구조사 2명 |
| 간호사 대 환자 비율 | 상시 1:3 (중증도에 따라 1:1~1:2) |
| 주요 환자 | 응급 처치 후 경과 관찰 환자, 전과/입원 대기 환자 |
| 상비 약품 | 아세트아미노펜 시럽(해열제), 이부프로펜 400mg(진통제), 에피네프린, 아트로핀, 아데노신 |
| 주요 장비 | 제세동기, 인공호흡기, 중심정맥관 삽입 키트, 이동형 X-ray, 이동형 심전도(ECG), 혈당 측정기 |

**운영 특이사항:**
- 24시간 365일 운영되며, 정응급 전문의를 포함한 응급의학과 전문의 3인이 3교대로 근무합니다.
- 최대 관찰 시간은 24시간이며, 24시간 초과 시 전문과 입원 또는 귀가를 결정합니다.
- 중증도 분류(KTAS) 결과에 따라 처치 우선순위를 결정하며, KTAS 1~2등급 환자는 즉시 처치 구역에 배정합니다.
- 모든 환자에 대해 내원 즉시 CBC, 심전도(ECG), 혈당검사를 시행하며, 필요 시 CT 촬영을 즉각 의뢰합니다.
- 감염 의심 환자는 격리실(음압)로 배정하며, 개인보호구(PPE) 착용을 의무화합니다.
- 소아 응급 환자 내원 시 소아과 박소아 전문의에게 즉시 협진 의뢰합니다.

### 2-6. 산부인과 병동 (6층)

| 항목 | 내용 |
|------|------|
| 병동명 | 산부인과 병동 |
| 위치 | 본관 6층 |
| 병상 수 | 15병상 |
| 병실 구성 | 4인실 2실, 2인실 2실, 1인실(분만 후 산모) 3실 |
| 담당 전문의 | 한산부 (산부인과) |
| 수간호사 | 1명 |
| 간호 인력 | 간호사 6명 (3교대), 조산사 2명, 간호조무사 2명 |
| 간호사 대 환자 비율 | 주간 1:4, 야간 1:5 |
| 주요 입원 환자 | 분만(자연분만, 제왕절개), 고위험 임신 관리, 부인과 수술 |
| 상비 약품 | 아세트아미노펜 시럽/정제(해열진통), 아목시실린 500mg(감염 예방) |
| 특수 시설 | 분만실 2실, 신생아실, 모유수유 상담실, 산전 초음파실 |

**운영 특이사항:**
- 한산부 전문의가 한미영(1995년생, 여성) 등 산전관리 환자 및 분만 환자를 관리합니다.
- 분만 후 산모의 활력징후를 첫 6시간 동안 1시간 간격으로 측정합니다.
- 제왕절개 후 환자는 수술 후 프로토콜(외과 병동과 동일)을 적용하며, 아목시실린 500mg(300원/캡슐) 기반 감염 예방 요법을 시행합니다.
- 신생아실과 연계하여 모자동실(rooming-in)을 운영합니다.
- 모유수유 상담: 조산사가 분만 후 1시간 이내 첫 모유수유를 지원합니다.
- 산전검사: 입원 시 CBC, 혈당검사, 소변검사, 간기능검사(LFT)를 시행합니다.
- 송지현(1988년생, 여성)이 부인과 복강경 수술 후 산부인과 병동에 입원한 사례에서, 수술 후 2일 만에 퇴원했습니다.

## 제3장. 환자 안전 관리

### 3-1. 환자 확인 절차 (Patient Identification)

**원칙:** 모든 의료 행위(투약, 수혈, 검사, 수술, 시술) 전에 최소 2가지 이상의 환자 확인 방법을 사용합니다.

**확인 방법:**

| 확인 수단 | 내용 | 적용 시점 |
|----------|------|----------|
| 환자 팔찌 | 성명, 등록번호, 생년월일, 혈액형 | 입원 시 착용, 퇴원 시 제거 |
| 구두 확인 | 환자에게 직접 성명과 생년월일 확인 질문 | 모든 의료 행위 전 |
| 바코드 스캔 | 팔찌 바코드를 PDA로 스캔하여 전자의무기록과 대조 | 투약, 수혈, 검체 채취 시 |
| 사진 대조 | EMR에 등록된 환자 사진과 대조 | 의식 불명 환자, 소아 환자 |

**사례:** 환자 김철수(1985년생, 남성, 혈액형 A+)에게 오메프라졸 20mg을 투약하기 전, 간호사가 팔찌를 확인하고 "성함과 생년월일을 말씀해 주세요"라고 구두 확인한 후, PDA로 팔찌 바코드를 스캔하여 처방전과 대조합니다.

**소아 환자 특이사항:** 박민준(2018년생, 남아) 및 윤서준(2020년생, 남아) 등 의사표현이 어려운 소아 환자는 보호자에게 확인하고, 팔찌 + 바코드 스캔을 필수로 시행합니다. 소아 팔찌에는 체중과 알레르기 정보를 추가 기재합니다.

### 3-2. 투약 안전 (Medication Safety)

**5 Right 원칙:**

| 원칙 | 확인 내용 | 확인 방법 |
|------|----------|----------|
| Right Patient (정확한 환자) | 환자 확인 (팔찌, 구두, 바코드) | 3-1 절차 적용 |
| Right Drug (정확한 약물) | 약물명, 함량, 제형 확인 | 처방전 대조, 약물 라벨 확인 |
| Right Dose (정확한 용량) | 처방 용량과 투여 용량 일치 | 체중 기반 계산 (소아), 용량 범위 확인 |
| Right Route (정확한 경로) | 경구, 정맥, 근육, 피하 등 | 처방전 투여 경로 확인 |
| Right Time (정확한 시간) | 투여 시각, 간격 | 투약 기록지 확인 |

**고위험 약물 관리:**

| 약물 | 위험 사항 | 추가 확인 절차 |
|------|----------|--------------|
| 아목시실린 500mg | 페니실린 알레르기 → 아나필락시스 | 투여 전 알레르기 확인 3회 (처방 시, 조제 시, 투약 시) |
| 이부프로펜 400mg | 위장관 출혈, 신기능 저하 | 위장관 병력 확인, 오메프라졸 병용 여부 |
| 수마트립탄 50mg | 심혈관계 이상 | 심전도(ECG) 결과 확인, 혈압 측정 |
| 아세트아미노펜 시럽 | 소아 과량 투여 → 간 독성 | 체중 재측정, 용량 이중 확인 (Double-check) |

**투약 오류 발생 시 대응:**
1. 즉시 투약 중단
2. 환자 활력징후 확인
3. 담당 전문의에게 즉시 보고
4. 필요 시 해독제 투여 (아세트아미노펜 과량: N-아세틸시스테인)
5. 투약 오류 보고서 작성 (환자안전보고시스템, KOPS)
6. 환자 및 보호자에게 고지
7. 재발 방지 대책 수립

### 3-3. 낙상 예방 (Fall Prevention)

**낙상 위험 평가:**

| 평가 항목 | 위험 인자 | 대상 환자 예시 |
|----------|----------|-------------|
| 연령 | 65세 이상, 6세 이하 | 정대호(1965년생), 박민준(2018년생), 윤서준(2020년생) |
| 보행 장애 | 수술 후, 골절, 마비 | 최수아(정형외과 수술 후) |
| 약물 | 진정제, 이뇨제, 항히스타민제 | 세티리진 10mg 투여 환자 (졸음 유발) |
| 의식 상태 | 혼돈, 섬망, 의식 저하 | 응급 관찰실 환자 |
| 배뇨 장애 | 빈뇨, 야뇨, 요실금 | 고령 환자, 이뇨제 복용 환자 |

**낙상 예방 중재:**

1. **환경 관리:**
   - 바닥 물기 즉시 제거, 미끄럼방지 매트 설치
   - 침대 높이 최하단 고정
   - 침대 난간 올림 (특히 야간, 소아, 고령자)
   - 콜벨 환자 손 닿는 곳에 배치
   - 야간 보조 조명 유지
   - 화장실 안전 손잡이 설치

2. **환자/보호자 교육:**
   - 입원 시 낙상 예방 교육 (서면 + 구두)
   - 이동 시 간호사 호출 안내
   - 미끄럼방지 슬리퍼 착용 권고

3. **고위험 환자 표시:**
   - 낙상 고위험 환자 팔찌에 노란색 밴드 추가
   - 침대 머리맡에 낙상 주의 표시
   - 간호사 인수인계 시 낙상 위험도 전달

4. **낙상 발생 시 대응:**
   - 환자 상태 즉시 확인 (의식, 통증, 손상 여부)
   - 담당 전문의 보고
   - 필요 시 CT 촬영, X-ray 촬영
   - 낙상 사고 보고서 작성
   - 원인 분석 및 재발 방지 대책

### 3-4. 감염 관리 (Infection Control)

**손 위생 (Hand Hygiene):**

| 시점 | 방법 | 소요시간 |
|------|------|---------|
| 환자 접촉 전 | 알코올 손 소독제 | 20초 이상 |
| 무균 시술 전 | 알코올 손 소독제 또는 손 씻기 | 20~40초 |
| 체액 노출 위험 후 | 비누와 물로 손 씻기 | 40~60초 |
| 환자 접촉 후 | 알코올 손 소독제 | 20초 이상 |
| 환자 주변 환경 접촉 후 | 알코올 손 소독제 | 20초 이상 |

**격리 지침:**

| 격리 유형 | 적용 상황 | 보호구 (PPE) | 격리 병실 |
|----------|----------|------------|----------|
| 접촉 격리 | MRSA, VRE, 다제내성균 | 가운, 장갑 | 1인실 또는 코호트 |
| 비말 격리 | 인플루엔자, 코로나바이러스 | 수술용 마스크, 고글 | 1인실 |
| 공기 격리 | 결핵, 홍역, 수두 | N95 마스크, 고글 | 음압 격리실 |
| 보호 격리 | 면역저하 환자 | 가운, 마스크, 장갑 | 양압 1인실 |

**병동별 감염 관리 추가 사항:**

- **외과 병동 (4층):** 수술 부위 감염(SSI) 예방을 위해 아목시실린 500mg(300원/캡슐) 투여 프로토콜 운영. 수술 부위 드레싱은 무균 술기로 시행. 이외과 전문의의 수술 후 환자 회진 시 수술 부위 감염 징후(발적, 열감, 삼출물) 확인.
- **소아 병동 (2층):** 전염성 질환(수두, 볼거리 등) 의심 소아 입원 시 즉시 격리. 놀이 공간 장난감은 매일 소독. 보호자 손 위생 교육 강화.
- **산부인과 병동 (6층):** 제왕절개 수술 후 상처 감염 예방. 신생아실 출입 시 손 위생 및 가운 착용 의무. 모유수유 시 유두 청결 관리 교육.
- **응급 관찰실 (1층):** 미확인 감염원 환자에 대해 표준주의(Standard Precaution) 적용. 격리실(음압) 2실 운영.

### 3-5. 응급 코드 체계 (Emergency Code System)

| 코드 | 상황 | 발동 방법 | 대응 팀 |
|------|------|----------|--------|
| Code Blue | 심정지/호흡정지 | 내선 119 + 방송 | CPR팀 (응급의학과 정응급 + 당직 전문의 + 간호사 3인) |
| Code Red | 화재 | 화재경보기 + 내선 119 | 소방팀 + 병동 전 직원 |
| Code White | 신생아 응급 | 내선 200 + 방송 | 소아과 박소아 + 신생아실 간호사 |
| Code Pink | 신생아/소아 유괴 | 내선 119 + 방송 | 보안팀 + 병동 전 직원 |
| Code Yellow | 대량 환자 발생 | 내선 100 + 방송 | 재난 대응팀 (전과 동원) |
| Code Silver | 폭력/위협 상황 | 내선 112 + 방송 | 보안팀 + 경찰 |
| Code Orange | 위험물질 유출 | 내선 119 + 방송 | 환경안전팀 |

**Code Blue 대응 절차:**
1. 환자 반응 확인 (어깨 두드리며 "괜찮으세요?" 호출)
2. 무반응 시 Code Blue 발동 (내선 119, 병동 위치 전달)
3. 가슴압박(CPR) 즉시 시작 (100~120회/분, 깊이 5cm)
4. 제세동기(AED) 가져와 부착
5. 정응급 전문의 도착 시 인계
6. 고급 기도유지(기관삽관), 정맥로 확보, 약물 투여(에피네프린 1mg IV)
7. 심전도(ECG) 모니터링
8. 상황 종료 후 Code Blue 기록지 작성

### 3-6. 수혈 안전

**수혈 전 확인 절차:**

| 단계 | 확인 내용 | 확인자 |
|------|----------|--------|
| 1. 혈액형 확인 | 환자 팔찌의 혈액형과 혈액 제제 라벨 대조 | 간호사 2인 |
| 2. 교차시험 | 교차시험 결과 적합 여부 확인 | 간호사 + 전문의 |
| 3. 환자 확인 | 팔찌 바코드 스캔 + 구두 확인 | 간호사 |
| 4. 혈액 제제 확인 | 혈액형, 유효기간, 제조번호 | 간호사 2인 |

**사례:** 환자 김철수(혈액형 A+)에게 수혈 시, 간호사 2인이 A+ 적혈구 제제의 라벨과 교차시험 결과를 확인합니다. 수혈 시작 후 15분간 집중 관찰(발열, 오한, 두드러기, 호흡곤란 여부)하며, 이상반응 발생 시 즉시 수혈을 중단하고 담당 전문의에게 보고합니다.
