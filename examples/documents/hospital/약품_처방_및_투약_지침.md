# 약품 처방 및 투약 지침

**서울중앙병원 약품 처방 및 투약 관리 지침서**

발행일: 2026년 3월 1일 | 개정판: 제9판 | 발행처: 서울중앙병원 약제팀

---

## 제1장. 총칙

### 1-1. 목적

본 지침서는 서울중앙병원에서 사용하는 주요 약품의 처방, 투약, 보관, 부작용 관리에 관한 표준 지침을 수립하여 환자 안전을 보장하고 의약품 사용의 적정성을 확보하는 것을 목적으로 합니다.

### 1-2. 적용 범위

본 지침은 서울중앙병원의 전 진료과(내과, 외과, 소아과, 정형외과, 응급의학과, 산부인과, 신경과)에서 처방하는 모든 약품에 적용됩니다. 모든 처방의(김내과, 이외과, 박소아, 최정형, 정응급, 한산부, 윤내과, 송신경)는 본 지침을 숙지하고 준수하여야 합니다.

### 1-3. 처방 원칙

1. 모든 약품 처방은 전자처방전달시스템(OCS)을 통해 이루어져야 합니다.
2. 처방 전 환자의 알레르기 정보, 현재 복용 약물, 간기능검사(LFT) 결과, 신기능 수치를 반드시 확인합니다.
3. 소아 환자(18세 이하)에 대한 처방 시 체중 기반 용량 산정을 필수로 합니다.
4. 65세 이상 고령 환자에 대한 처방 시 감량 투여 여부를 검토합니다.
5. 임산부에 대한 처방 시 FDA 임신 카테고리를 확인하고, 산부인과 한산부 전문의와 협의합니다.

## 제2장. 주요 약품별 처방 지침

### 2-1. 오메프라졸 20mg (소화기)

| 항목 | 내용 |
|------|------|
| 약품명 | 오메프라졸 (Omeprazole) 20mg 장용성 캡슐 |
| 약효분류 | 양성자펌프억제제 (PPI) |
| 단가 | 250원/정 |
| 주요 적응증 | 위식도역류질환(GERD), 위궤양, 십이지장궤양, Zollinger-Ellison 증후군, 헬리코박터 파일로리 제균 요법 |
| 주 처방과 | 내과 (김내과 전문의) |
| 용법/용량 | 성인: 1일 1회 20mg, 아침 식전 30분에 복용. 중증 시 40mg까지 증량 가능 |
| 치료 기간 | 위궤양: 4~8주 / GERD: 4~8주 / 헬리코박터 제균: 7~14일 (3제 요법) |
| 금기사항 | 오메프라졸 과민반응, 릴피비린 병용 금기 |
| 주요 부작용 | 두통(2.4%), 설사(1.9%), 복통(1.6%), 오심(1.3%), 장기 복용 시 비타민B12 결핍, 저마그네슘혈증 |
| 보관 조건 | 실온(15~25도), 습기 차단, 차광 보관 |

**약물 상호작용:**
- 클로피도그렐: 병용 시 클로피도그렐의 항혈소판 효과 감소 가능 — 순환기내과 협의 필요
- 메토트렉세이트: 메토트렉세이트 혈중 농도 상승 가능 — 고용량 메토트렉세이트 투여 시 PPI 중단 고려
- 디곡신: 디곡신 흡수 증가 가능 — 혈중 농도 모니터링
- 이부프로펜 400mg과 병용 시: 위장관 보호 목적으로 병용 처방 가능 (이부프로펜의 위장관 부작용 경감)

**소아 투여:** 체중 10~20kg: 10mg/일, 20kg 이상: 20mg/일. 소아과 박소아 전문의 처방 시 체중 기반 용량 확인 필수.

**고령자 투여:** 65세 이상에서도 용량 조절 불필요하나, 장기 복용(12주 이상) 시 마그네슘 수치 및 CBC 정기 모니터링 권장.

**환자 교육 포인트:**
- 캡슐을 씹거나 부수지 않고 통째로 복용
- 아침 식사 30분 전 복용이 가장 효과적
- 증상 개선 후에도 처방된 기간 동안 복용 지속

### 2-2. 이부프로펜 400mg (진통제)

| 항목 | 내용 |
|------|------|
| 약품명 | 이부프로펜 (Ibuprofen) 400mg 정제 |
| 약효분류 | 비스테로이드성 항염증제 (NSAIDs) |
| 단가 | 180원/정 |
| 주요 적응증 | 관절통, 근육통, 두통, 치통, 생리통, 수술 후 통증, 발열 |
| 주 처방과 | 정형외과 (최정형), 외과 (이외과), 신경과 (송신경) |
| 용법/용량 | 성인: 1회 400mg, 1일 3회, 식후 복용. 최대 1일 2,400mg |
| 치료 기간 | 급성 통증: 3~7일 / 만성 통증: 최소 유효 용량으로 최단 기간 |
| 금기사항 | 위궤양 활동기, 중증 심부전, 아스피린 천식, 임신 말기(3분기), 중증 간/신장 장애 |
| 주요 부작용 | 위장관 장애(소화불량, 위통, 오심), 어지럼증, 부종, 드물게 위장관 출혈 |
| 보관 조건 | 실온(15~30도), 밀폐 용기, 직사광선 차단 |

**약물 상호작용:**
- **아목시실린 500mg과의 병용:** 일반적으로 안전하나, 이부프로펜이 아목시실린의 신장 배설을 지연시킬 수 있어 고용량 장기 병용 시 신기능 모니터링 권장. 외과 이외과 전문의가 수술 후 항생제+진통제 병용 처방 시 이 상호작용을 고려해야 합니다.
- 와파린: 출혈 위험 증가 — 항응고제 복용 환자에게 처방 시 INR 모니터링
- 리튬: 리튬 혈중 농도 상승 — 신경과 환자에게 리튬 병용 시 주의
- ACE 억제제/ARB: 혈압강하 효과 감소, 신기능 악화 가능
- 수마트립탄 50mg과의 병용: 편두통 환자에서 이부프로펜(진통)+수마트립탄(편두통 특이적 치료) 동시 처방 가능하나, 시간 간격 2시간 이상 권장

**소아 투여:** 6개월 이상, 체중 기반 5~10mg/kg/회, 1일 3~4회. 최대 40mg/kg/일. 박소아 전문의 처방 시 체중 확인 필수. 영아(6개월 미만)에게는 투여 금지.

**고령자 투여:** 정대호(1965년생, 남성) 등 60세 이상 환자에게 처방 시 최소 유효 용량(200~400mg)으로 시작하고, 위장관 보호를 위해 오메프라졸 20mg 병용을 고려합니다. 혈당검사, CBC 정기 모니터링을 권장합니다.

### 2-3. 아목시실린 500mg (항생제)

| 항목 | 내용 |
|------|------|
| 약품명 | 아목시실린 (Amoxicillin) 500mg 캡슐 |
| 약효분류 | 페니실린계 항생제 (광범위) |
| 단가 | 300원/캡슐 |
| 주요 적응증 | 상기도 감염, 중이염, 부비동염, 요로감염, 피부연조직 감염, 헬리코박터 제균 요법, 수술 후 감염 예방 |
| 주 처방과 | 외과 (이외과), 내과 (김내과), 소아과 (박소아), 산부인과 (한산부) |
| 용법/용량 | 성인: 1회 500mg, 1일 3회 (8시간 간격), 식사와 무관 |
| 치료 기간 | 일반 감염: 7~14일 / 헬리코박터 제균: 14일 / 수술 후 예방: 3~5일 |
| 금기사항 | 페니실린 과민반응, 전염성 단핵구증 (피부 발진 위험), 중증 간장애 |
| 주요 부작용 | 설사(4.7%), 오심(2.1%), 피부 발진(1.8%), 드물게 아나필락시스 |
| 보관 조건 | 실온(15~25도), 밀폐 보관 |

**약물 상호작용:**
- **이부프로펜 400mg과의 병용:** 상기 2-2 참조. 수술 후 항생제+진통제 병용 시 통상적이나, 장기 병용 시 신기능 모니터링 필요.
- 메토트렉세이트: 메토트렉세이트 혈중 농도 상승 — 병용 주의
- 와파린: 항응고 효과 증강 가능 — INR 추적 권장
- 경구피임약: 피임 효과 감소 가능 — 환자 교육 필요 (산부인과 한산부 전문의 처방 시 주의)

**소아 투여:** 소아과 박소아 전문의가 환자 박민준(2018년생, 남아) 및 윤서준(2020년생, 남아) 등 소아 환자에게 처방 시 체중 기반 용량을 산정합니다. 체중 기반 20~40mg/kg/일, 3회 분할 투여. 5세 미만 소아는 분말/현탁액 제형 사용. 최대 용량 성인량(1,500mg/일) 초과 금지.

**임산부 투여:** FDA 카테고리 B. 임산부에게 비교적 안전하게 투여 가능. 산부인과 한산부 전문의가 한미영(1995년생, 여성) 등 임산부에게 감염 치료 목적으로 처방 가능. 수유 중에도 투여 가능하나 영아의 설사 여부 관찰.

**처방 전 확인사항:**
- 페니실린 알레르기 병력 반드시 확인 (초진 등록 시 김철수 등 환자 알레르기 정보 참조)
- 알레르기 양성 시 세팔로스포린 교차반응 평가 후 대체 항생제 선정
- 헬리코박터 제균 시 오메프라졸 20mg + 아목시실린 500mg + 클래리스로마이신 500mg 3제 요법

### 2-4. 덱스트로메토르판 (기침약)

| 항목 | 내용 |
|------|------|
| 약품명 | 덱스트로메토르판 (Dextromethorphan) 15mg/5mL 시럽 및 30mg 정제 |
| 약효분류 | 중추성 진해제 (비마약성) |
| 단가 | 150원/정 (30mg), 시럽 5,000원/120mL |
| 주요 적응증 | 감기, 급성 기관지염에 의한 마른기침 (비생산성 기침) |
| 주 처방과 | 내과-호흡기 (윤내과 전문의), 소아과 (박소아) |
| 용법/용량 | 성인: 1회 30mg, 1일 3~4회. 최대 120mg/일 |
| 치료 기간 | 7일 이내 (기침 지속 시 원인 정밀 검사 필요) |
| 금기사항 | MAO 억제제 병용(세로토닌 증후군 위험), 습성 기침(가래 동반), 만성 기침 |
| 주요 부작용 | 졸음, 어지럼증, 오심, 드물게 세로토닌 증후군 (SSRI 병용 시) |
| 보관 조건 | 실온(15~30도), 시럽은 개봉 후 30일 이내 사용 |

**소아 투여:**
- 2~6세: 7.5mg/회, 1일 3~4회 (시럽 제형 사용)
- 6~12세: 15mg/회, 1일 3~4회
- 12세 이상: 성인 용량
- 2세 미만: 투여 금지

**고령자 투여:** 정대호(1965년생) 등 고령 환자에서 졸음 및 어지럼증 발생 빈도가 높으므로 운전 및 기계 조작 주의 안내. 초기 용량 15mg/회로 시작 권장.

**약물 상호작용:**
- SSRI/SNRI 항우울제: 세로토닌 증후군 위험 — 신경과 송신경 전문의 처방 시 병용 약물 확인 필수
- MAO 억제제: 절대 병용 금기 (투여 중단 후 14일 이상 간격)
- 세티리진 10mg과의 병용: 안전하게 병용 가능하나 졸음 효과 상가 — 운전 주의 안내

**윤내과 전문의 처방 지침:** 만성 기침 환자에게 덱스트로메토르판을 7일 이상 처방하지 않습니다. 7일 경과 후에도 기침이 지속되면 흉부 X-ray 및 CT 촬영을 의뢰하여 원인을 감별합니다.

### 2-5. 수마트립탄 50mg (두통약)

| 항목 | 내용 |
|------|------|
| 약품명 | 수마트립탄 (Sumatriptan) 50mg 정제 |
| 약효분류 | 세로토닌 수용체 작용제 (트립탄계) |
| 단가 | 1,200원/정 |
| 주요 적응증 | 편두통 (전조 유무 불문), 군발성 두통 |
| 주 처방과 | 신경과 (송신경 전문의) |
| 용법/용량 | 성인: 편두통 발작 시 50mg 1회 경구 복용. 효과 불충분 시 2시간 후 50mg 추가 가능. 최대 200mg/24시간 |
| 치료 기간 | 발작 시 급성기 치료제 (예방 목적 연용 금지) |
| 금기사항 | 관상동맥 질환, 뇌혈관 질환, 말초혈관 질환, 조절되지 않는 고혈압, MAO 억제제 투여 중, 중증 간장애 |
| 주요 부작용 | 흉부 압박감/통증(3.1%), 어지럼증(2.4%), 졸음(2.1%), 오심(1.8%), 사지 저림 |
| 보관 조건 | 실온(15~30도), 차광, 밀폐 보관 |

**약물 상호작용:**
- SSRI/SNRI: 세로토닌 증후군 위험 — 병용 시 최소 유효 용량 사용, 증상 모니터링
- 에르고타민: 병용 금기 (혈관 수축 상가 작용) — 수마트립탄 투여 후 24시간 이내 에르고타민 투여 금지
- MAO 억제제: 수마트립탄 대사 억제 — 절대 병용 금기
- 이부프로펜 400mg: 편두통 환자에서 병용 가능 (상기 2-2 참조)

**고령자 투여:** 65세 이상에서의 안전성 데이터가 제한적이므로, 정대호(1965년생, 남성) 등 고령 환자에게 처방 시 심전도(ECG) 검사를 선행하고, 심혈관 위험 인자를 평가합니다. 초회 투여 시 25mg으로 시작 고려.

**소아 투여:** 18세 미만에서의 사용은 권장되지 않습니다. 소아 편두통에는 아세트아미노펜 또는 이부프로펜 1차 선택.

**송신경 전문의 처방 프로토콜:**
1. 편두통 진단 확정 (국제두통학회 기준)
2. 심전도(ECG) 정상 확인
3. 혈압 측정 (수축기 140mmHg 미만, 이완기 90mmHg 미만)
4. 초회 50mg 처방, 효과 평가 후 용량 조절
5. 월 8일 이상 두통 발생 시 예방 치료 전환 (수마트립탄은 발작기 치료제)

## 제3장. 약물 이상반응 관리

### 3-1. 약물 이상반응 보고 절차

1. 이상반응 발생 즉시 담당 의사 및 약제팀에 보고
2. 전자의무기록(EMR)에 "약물이상반응" 탭에 기록
3. 중대한 이상반응(아나필락시스, 스티븐스-존슨 증후군 등)은 식품의약품안전처에 보고
4. 해당 약물 알레르기 정보를 환자 프로필에 영구 등록

### 3-2. 아나필락시스 응급 대응

아목시실린 500mg 투여 후 아나필락시스 발생 시:
1. 즉시 투약 중단
2. 에피네프린 0.3mg 근육주사 (소아: 0.15mg)
3. 기도 확보, 산소 투여
4. 정맥로 확보, 수액 투여
5. 응급의학과 정응급 전문의 호출 (응급센터 내선 119)
6. 활력징후 모니터링 (CBC, ECG 시행)
7. 입원 관찰 (최소 4시간, 이상형 반응 대비 24시간 권장)
