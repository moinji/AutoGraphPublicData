=== 사내 규정 요약 (2026년 개정판) ===

1. 근무 규정
   - 주 40시간 근무 (코어타임 10:00~16:00)
   - 유연근무제: 08:00~10:00 출근, 17:00~19:00 퇴근
   - 재택근무: 주 2일까지 가능 (팀장 승인)
   - 초과근무: 사전 승인 필수, 월 52시간 한도

2. 보안 규정
   - 사내 자료 외부 반출 금지
   - 개인 USB 사용 금지
   - 화면 잠금: 자리 비울 시 필수 (Win+L)
   - 비밀번호: 영문+숫자+특수문자 12자 이상, 90일마다 변경
   - 2단계 인증(MFA) 필수 적용

3. 경비 규정
   - 출장비: 교통비 실비 + 숙박 1박 15만원 한도 + 식비 1일 5만원
   - 법인카드: 업무용도만 사용, 사적 사용 시 전액 변상
   - 경비 정산: 지출일로부터 7일 이내

4. 직급 체계
   사원 → 대리 → 과장 → 차장 → 부장 → 이사 → 상무 → 전무 → 부사장 → 사장

   기술직: 주니어 → 시니어 → 리드 → 프린시플 → 펠로우

5. 징계 규정
   - 경고 → 감봉 → 정직 → 해고
   - 3회 경고 = 감봉 1개월
   - 무단결근 3일 이상: 정직 처분
