**문서번호**: HR-REC-2026-001
**시행일자**: 2026년 1월 1일
**최종 개정**: 2026년 4월 1일
**관리부서**: 인사팀 (박인사 팀장)
**승인권자**: 김대표 대표이사

## 제1장 총칙

### 제1조 (목적)
본 가이드는 당사의 인재 채용 및 신규 입사자 온보딩에 관한 표준 절차와 기준을 규정하여, 우수 인재의 확보와 조기 정착을 체계적으로 지원함을 목적으로 한다.

### 제2조 (채용 원칙)
1. **능력주의**: 학력, 성별, 연령에 관계없이 직무 역량과 잠재력을 기준으로 채용한다.
2. **공정성**: 모든 지원자에게 동일한 평가 기준을 적용한다.
3. **투명성**: 채용 절차와 기준을 지원자에게 사전 공개한다.
4. **적합성**: 직무에 필요한 스킬(Python, Java, React, AWS, 프로젝트 관리, 데이터 분석, 영어 비즈니스, 리더십)과 조직 문화 적합도를 종합 평가한다.

### 제3조 (2026년 채용 계획)

인사팀 박인사 팀장이 각 부서의 인력 수요를 취합하여 연간 채용 계획을 수립한다.

| 부서 | 직급 | 인원 | 주요 스킬 요건 | 관련 프로젝트 | 상태 |
|------|------|:----:|--------------|-------------|:----:|
| 개발1팀 | 시니어 | 1명 | Python, AWS, 데이터 분석 | GraphRAG SaaS 개발 | 채용 중 |
| 개발2팀 | 주니어 | 2명 | React, Java | 모바일 앱 리뉴얼 | 채용 중 |
| 해외영업팀 | 대리 | 1명 | 영어 비즈니스, 데이터 분석 | 해외 시장 진출 | 채용 예정 |
| QA팀 | 주니어 | 1명 | Python, AWS | CI/CD 유지보수 | 하반기 예정 |
| 재무팀 | 사원 | 1명 | 데이터 분석 | ERP 시스템 도입 | 하반기 예정 |

## 제2장 채용 절차

### 제4조 (채용 요청)

1. **인력 수요 발생**: 팀장이 인력 충원 필요성을 판단한다.
   - 예: 정개발 팀장(개발1팀)이 GraphRAG SaaS 개발의 Phase 3(SaaS 플랫폼) 착수를 위해 시니어 개발자 1명 충원 요청
   - 예: 서개발 시니어(개발2팀 기술 리드)가 모바일 앱 리뉴얼 프론트엔드 개발을 위해 주니어 2명 충원 건의

2. **채용 요청서 작성**: 팀장이 인력 요청서를 작성하여 본부장에게 제출한다.
   - 요청 항목: 직급, 인원, 필수 스킬, 우대 스킬, 예상 연봉, 입사 희망 시기
   - 기술본부의 경우 최기술 본부장(연봉 1억 2,000만 원)이 검토 후 인사팀에 전달

3. **예산 확인**: 재무팀 이재무 팀장이 해당 부서의 인건비 예산을 확인한다.

4. **채용 승인**: 인사팀 박인사 팀장이 채용 계획과의 정합성을 검토하고, 김대표 대표이사가 최종 승인한다. (팀장급 이상 채용 시 대표이사 직접 면접 필수)

### 제5조 (채용 공고)

1. **공고 채널**
   - 사내: 사내 게시판, 사내 메신저 (내부 추천 우선)
   - 외부: 잡코리아, 사람인, 원티드, 링크드인, 로켓펀치
   - 기술 직군: GitHub Jobs, 프로그래머스, 백준

2. **공고 기간**: 최소 2주, 최대 4주

3. **공고 내용 필수 항목**
   - 회사 소개 및 팀 소개
   - 담당 업무 및 관련 프로젝트 (예: "GraphRAG SaaS 개발 프로젝트, 예산 5억 원 규모")
   - 자격 요건 (필수/우대 스킬)
   - 급여 범위 (직급별 밴드 공개)
   - 복리후생 주요 항목
   - 근무지 (서울 본사, 해당 층수 명시)

### 제6조 (서류 전형)

1. **접수 서류**: 이력서, 자기소개서, 포트폴리오(기술직), 경력기술서(경력직)
2. **검토 기준**

| 평가 항목 | 배점 | 기준 |
|----------|:----:|------|
| 직무 관련 경력 | 30점 | 해당 직무 경력 연수 및 관련성 |
| 보유 스킬 매칭 | 30점 | 필수 스킬 보유 여부 |
| 학력/자격증 | 15점 | 관련 학위, AWS 자격증 등 |
| 자기소개서 | 15점 | 지원 동기, 성장 계획 |
| 포트폴리오 | 10점 | 기술직에 한함 |

3. **서류 통과 기준**: 총점 60점 이상
4. **서류 검토 기한**: 접수 마감 후 5영업일 이내
5. **검토자**: 인사팀(1차) → 해당 팀장(2차)

### 제7조 (면접 전형)

#### 7.1 면접 단계

| 단계 | 면접관 | 시간 | 평가 항목 |
|------|--------|:----:|----------|
| 1차: 실무 면접 | 팀장 + 시니어 | 60분 | 직무 역량, 기술 심층, 문제 해결력 |
| 2차: 임원 면접 | 본부장 + 인사팀장 | 45분 | 조직 적합도, 성장 잠재력, 커뮤니케이션 |
| 3차: 대표 면접 | 대표이사 | 30분 | 비전 공유, 핵심 가치 적합성 (팀장급 이상 필수) |

#### 7.2 부서별 실무 면접 상세

**개발1팀 (정개발 팀장, 한개발 시니어 면접관)**

|----------|------|:----:|
| 코딩 테스트 | Python 알고리즘 문제 2개 (60분) | 30점 |
| 시스템 설계 | GraphRAG 관련 아키텍처 설계 질의 | 25점 |
| 기술 질의 | FastAPI, Neo4j, PostgreSQL 경험 | 20점 |
| 프로젝트 경험 | 과거 프로젝트 심층 질의 | 15점 |

| 평가 영역 | 내용 | 배점 |
|----------|------|:----:|
| 코딩 테스트 | React 컴포넌트 구현 과제 (60분) | 30점 |

| 기술 질의 | React Hooks, 상태 관리, 성능 최적화 | 25점 |
| 프론트엔드 심화 | TypeScript, 테스트 전략 | 15점 |
| 협업/소통 | 디자이너/백엔드 협업 사례 | 10점 |

서개발 시니어가 기술 면접관으로서 React 심화 역량을 중점 평가한다. 모바일 앱 리뉴얼 프로젝트(예산 2억 원) 참여를 전제로 한 실전형 과제를 출제한다.

### 제8조 (기술 평가)

기술 직군(개발1팀, 개발2팀, QA팀)은 면접 전 사전 기술 평가를 실시한다.

1. **온라인 코딩 테스트** (서류 통과 후 3일 이내)
   - 플랫폼: 프로그래머스 또는 자체 플랫폼
   - 문제 수: 3문제 (Easy 1, Medium 1, Hard 1)
   - 시간: 90분
   - 합격 기준: 2문제 이상 정답

2. **과제 전형** (시니어급 이상)
   - 실제 업무와 유사한 미니 프로젝트 (3~5일 소요)
   - 개발1팀: FastAPI + Neo4j 기반 API 구현
   - 개발2팀: React 기반 대시보드 구현
   - QA팀: 테스트 자동화 스크립트 작성

3. **기술 발표** (팀장급)
   - 과거 프로젝트 아키텍처 발표 (30분 + Q&A 15분)
   - 심사위원: 최기술 본부장, 해당 팀장, 인사팀장

### 제9조 (처우 협의 및 오퍼)

1. **연봉 결정 기준**: 직급별 밴드 내에서 경력, 스킬, 면접 결과를 종합하여 결정
   - 주니어(5급): 4,000만 ~ 6,500만 원 (예: 윤개발 주니어 5,200만 원)
   - 시니어(4급): 6,000만 ~ 9,000만 원 (예: 한개발 시니어 7,800만 원)
   - 팀장(3급): 8,000만 ~ 1억 1,000만 원 (예: 정개발 팀장 9,500만 원)
   - 본부장(2급): 1억 ~ 1억 5,000만 원 (예: 최기술 본부장 1억 2,000만 원)

2. **오퍼 발송**: 최종 합격 후 3영업일 이내 서면 오퍼 발송
3. **오퍼 유효 기간**: 발송일로부터 7영업일
4. **입사일 조율**: 인사팀 박인사 팀장이 해당 팀장과 협의하여 결정

## 제3장 온보딩 프로그램

### 제10조 (온보딩 개요)

온보딩 프로그램은 신규 입사자가 회사에 빠르게 적응하고 업무 성과를 낼 수 있도록 지원하는 체계적 프로그램이다. 총 3개월간 진행되며, 수습 평가와 연계된다.

**기술 직군 추가 활동 (Week 1)**
- 코드 저장소(GitHub) 접근 권한 부여 및 브랜치 전략 안내
- 코딩 컨벤션 및 코드 리뷰 프로세스 교육
- 개발 환경 셋업 완료 확인 (Docker, IDE, 데이터베이스 연결)
- 간단한 이슈(Good First Issue) 1건 할당

**기술 직군 Month 1 마일스톤**
- 개발1팀: 코드 리뷰 3회 이상 참여, PR(Pull Request) 5건 이상 제출
- 개발2팀: React 컴포넌트 3개 이상 독립 구현
- QA팀: 테스트 케이스 20건 이상 작성, CI/CD 파이프라인 1건 이상 수정

### 제14조 (수습 기간 프로그램 - Month 1~3)

| 월 | 활동 | 평가 항목 |
|:--:|------|----------|
| 1개월 | 기본 업무 독립 수행, 필수 교육 이수 | 적응도, 학습 속도 |
| 2개월 | 프로젝트 실질 기여 시작, 심화 교육 | 업무 품질, 협업 |
| 3개월 | 독립 업무 수행, 수습 종료 평가 | 성과, 역량, 조직 적합도 |

수습 종료 1주 전, 직속 상관(팀장)과 인사팀 박인사 팀장이 합동 평가를 실시한다. 평가 70점 이상 시 정규직으로 전환한다.

## 제4장 멘토링 제도

### 제15조 (멘토 배정 기준)

| 항목 | 기준 |
|------|------|
| 멘토 자격 | 동일 팀 시니어급 이상, 근속 2년 이상 |
| 배정 시기 | 입사 첫날 |
| 멘토링 기간 | 3개월 (수습 기간 종료 시까지) |
| 정기 면담 | 주 1회, 30분 이상 |
| 멘토 수당 | 월 10만 원 (멘토링 기간 동안) |

**부서별 멘토 배정 사례**

| 신규 입사자 (예시) | 멘토 | 비고 |
|-------------------|------|------|
| 개발1팀 주니어 (2023년 사례) | 한개발 시니어 | 윤개발 주니어의 멘토로 배정, 성공적 온보딩 |
| 개발2팀 주니어 (2026년 예정) | 서개발 시니어 | 모바일 앱 리뉴얼 프로젝트 투입 예정 |
| 국내영업팀 대리 (기존) | 임영업 팀장 | 강영업 대리의 멘토 역할 수행 |

윤개발 주니어(2023년 입사, 연봉 5,200만 원)의 온보딩 사례는 당사의 모범적인 멘토링 성공 사례로, 한개발 시니어(연봉 7,800만 원)의 체계적인 지도 하에 3개월 만에 GraphRAG SaaS 개발 프로젝트에 실질적으로 기여할 수 있는 수준에 도달하였다.

### 제16조 (멘토의 역할)

1. 업무 지도: 직무 수행에 필요한 기술과 프로세스 교육
2. 조직 적응 지원: 사내 문화, 비공식 규범, 인맥 형성 지원
3. 경력 상담: 경력 개발 방향 및 교육 과정 추천
   - 예: Python 고급 과정(40시간), React 심화(32시간), 데이터 분석 입문(24시간) 등 적합한 교육 추천
4. 정서적 지원: 입사 초기 불안감 해소, 고충 상담
5. 피드백 제공: 주간 피드백, 수습 평가 시 의견 제출
