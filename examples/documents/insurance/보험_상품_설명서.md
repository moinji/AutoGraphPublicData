# 보험 상품 설명서

**문서번호**: PD-2026-001
**시행일자**: 2026년 1월 1일
**개정이력**: 2026.01.01 초판 발행 / 2026.04.01 보장한도 개정

---

## 제1장 총칙

### 제1조 (목적)
본 문서는 당사가 판매하는 보험 상품의 주요 내용, 보장 범위, 보험료 산출 기준, 가입 조건 및 유의사항을 안내하기 위하여 작성되었다. 가입자는 본 설명서를 충분히 숙지한 후 청약서에 서명하여야 하며, 설계사는 본 설명서의 핵심 내용을 가입 희망자에게 반드시 설명하여야 한다.

### 제2조 (적용 범위)
본 설명서는 2026년 1월 1일 이후 신규 체결되는 개인보험 계약에 적용된다. 단체보험 및 기업보험은 별도의 약관을 따른다.

### 제3조 (용어 정의)
| 용어 | 정의 |
|------|------|
| 보험계약자 | 보험회사와 계약을 체결하고 보험료 납입 의무를 지는 자 |
| 피보험자 | 보험사고의 대상이 되는 자 |
| 보험수익자 | 보험금을 수령하는 자 |
| 보험기간 | 계약이 유효한 기간으로 책임개시일부터 만기일까지 |
| 면책기간 | 계약 체결 후 보장이 개시되지 않는 대기 기간 |
| 갱신 | 보험기간 만료 시 동일 조건 또는 변경 조건으로 계약을 연장하는 것 |

### 제4조 든든한 종합보험

#### 1. 상품 개요

| 항목 | 내용 |
|------|------|
| 상품명 | 든든한 종합보험 |
| 상품 유형 | 종합보험 |
| 표준 월 보험료 | 150,000원 (40세 기준, 비흡연 표준체) |
| 보험기간 | 20년 만기 / 80세 만기 선택 |
| 납입기간 | 10년납 / 15년납 / 20년납 / 전기납 |
| 가입연령 | 만 19세 ~ 만 65세 |
| 피보험자 범위 | 계약자 본인, 배우자, 자녀 (별도 특약) |

#### 2. 보장 내역

든든한 종합보험은 질병, 상해, 사망을 종합적으로 보장하는 당사의 대표 상품이다. 다음의 보장 항목이 기본 계약에 포함된다.

| 보장 항목 | 보장 금액 | 지급 조건 |
|-----------|-----------|-----------|
| 일반 입원비 | 1일당 50,000원 (최대 180일) | 질병 또는 상해로 4일 이상 입원 시 4일째부터 |
| 수술비 | 정액 1,000,000원 | 약관 지정 수술 시 (1~5종 분류) |
| 상해 후유장해 | 최대 1억원 (장해율 비례) | 3% 이상 후유장해 확정 시 |
| 사망 보험금 | 1억원 | 질병 또는 상해 사망 시 |
| 통원 의료비 | 1회당 최대 250,000원 (연 180회) | 외래 진료 시 공제금액 차감 후 |

#### 3. 보험료 산출 기준

보험료는 피보험자의 연령, 성별, 직업군, 건강 상태(표준체/우량체/비표준체)에 따라 차등 적용된다. 아래는 연령별 표준 보험료 예시이다.

| 연령 | 남성 (비흡연) | 남성 (흡연) | 여성 (비흡연) | 여성 (흡연) |
|------|:------------:|:-----------:|:------------:|:-----------:|
| 30세 | 120,000원 | 138,000원 | 105,000원 | 120,750원 |
| 40세 | 150,000원 | 172,500원 | 131,250원 | 150,940원 |
| 50세 | 198,000원 | 227,700원 | 173,250원 | 199,240원 |
| 60세 | 270,000원 | 310,500원 | 236,250원 | 271,690원 |

#### 4. 가입 적합 고객

- 가정의 주 소득자로서 종합적인 위험 보장이 필요한 고객
- 단일 보험으로 질병, 상해, 사망 보장을 통합 관리하고자 하는 고객
- 예시: 가입자A 김민수(1985년생, 서울 강남구 거주)는 40세 전후로 종합적인 가족 보장을 설계하기 위해 든든한 종합보험에 가입하였으며, 설계사 김설계(서울 지역, 자격번호 IA-2015-001)가 니즈 분석을 통해 20년 만기, 15년납 플랜을 추천하였다.

#### 5. 면책기간 및 감액기간

- 질병 관련 보장: 계약일로부터 90일 경과 후 보장 개시
- 상해 관련 보장: 계약일 즉시 보장 개시
- 암 진단 특약 추가 시: 계약일로부터 90일 면책기간 적용

#### 6. 갱신 조건

본 상품은 비갱신형이며, 납입 완료 후에도 보험기간 만료 시까지 보장이 유지된다. 단, 80세 만기 선택 시 만기 도래 후 보장 종료되며, 갱신 불가하다.

### 제5조 안심 암보험

#### 1. 상품 개요

| 항목 | 내용 |
|------|------|
| 상품명 | 안심 암보험 |
| 상품 유형 | 질병보험 (암 특화) |
| 표준 월 보험료 | 80,000원 (40세 기준, 비흡연 여성) |
| 보험기간 | 10년 만기 갱신형 / 80세 만기 비갱신형 |
| 납입기간 | 10년납 / 20년납 / 전기납 |
| 가입연령 | 만 20세 ~ 만 60세 |

#### 2. 보장 내역

| 보장 항목 | 보장 금액 | 지급 조건 |
|-----------|-----------|-----------|
| 암 진단비 | 일시금 50,000,000원 | 일반암 최초 진단 확정 시 |
| 소액암 진단비 | 일시금 10,000,000원 | 유사암(갑상선암, 기타피부암 등) 진단 시 |
| 암 입원비 | 1일당 100,000원 (최대 120일) | 암 치료 목적 입원 시 |
| 암 수술비 | 정액 5,000,000원 | 암 직접 치료 수술 시 |
| 암 통원 치료비 | 1회당 200,000원 (연 120회) | 항암방사선, 항암약물 치료 시 |

#### 3. 가입 적합 고객

- 가족력상 암 발생 위험이 높은 고객
- 국민건강보험 비급여 항목에 대한 추가 보장이 필요한 고객
- 예시: 가입자B 이수진(1990년생, 경기 성남시 거주)은 가족력(어머니 유방암 병력)을 고려하여 안심 암보험에 가입하였다. 이설계(경기 지역)가 비갱신형 80세 만기 플랜으로 설계하였으며, 월 보험료 80,000원으로 암 진단비 5,000만원 보장을 확보하였다. 실제로 이수진 가입자는 2026년 2월 유방암 진단을 받아 CLM-2026-002 건으로 암 진단비 5,000만원을 청구하였으며, 현재 심사 진행 중(processing)이다.

#### 4. 면책기간

- 모든 암 보장: 계약일로부터 90일 면책기간 적용
- 90일 이내 암 진단 시 계약 무효 처리 및 납입보험료 전액 환급
- 면책기간 경과 후 최초 1년간 일반암 진단비의 50%만 지급 (감액기간)

#### 5. 갱신 조건 (갱신형 선택 시)

- 10년 만기 도래 시 자동 갱신 (최대 80세까지)
- 갱신 시 보험료는 갱신 시점의 나이 및 위험률에 따라 재산출
- 갱신 거절 사유: 없음 (무조건 갱신 보장)

### 제6조 운전자 보험

#### 1. 상품 개요

| 항목 | 내용 |
|------|------|
| 상품명 | 운전자 보험 |
| 상품 유형 | 상해보험 (운전 특화) |
| 표준 월 보험료 | 45,000원 (40세 기준) |
| 보험기간 | 3년 만기 갱신형 |
| 납입기간 | 전기납 (3년) |
| 가입연령 | 만 19세 ~ 만 70세 |

#### 2. 보장 내역

| 보장 항목 | 보장 금액 | 지급 조건 |
|-----------|-----------|-----------|
| 교통사고 처리지원금 | 최대 30,000,000원 | 교통사고 야기 시 형사합의금 |
| 벌금 | 최대 20,000,000원 | 교통사고 벌금 확정 시 |
| 변호사 선임비 | 최대 2,000,000원 | 형사 기소 시 |
| 상해 후유장해 | 최대 1억원 (장해율 비례) | 자동차 사고로 인한 후유장해 |
| 자동차 사고 입원비 | 1일당 50,000원 (최대 180일) | 자동차 사고 입원 시 |

#### 3. 가입 적합 고객

- 일상적으로 자동차를 운전하는 모든 운전자
- 영업용 차량 운전자, 출퇴근 장거리 운전자
- 예시: 가입자C 박준호(1978년생, 부산 해운대구 거주)는 매일 출퇴근 및 영업 목적으로 차량을 운행하여 운전자 보험에 가입하였다. 박설계(부산 지역)가 교통사고 처리지원금 3,000만원, 벌금 2,000만원 한도로 설계하였다. 박준호 가입자는 2026년 1월 교통사고로 입원하여 CLM-2026-001 건으로 입원비 350만원을 청구, 심사 완료(settled) 후 지급이 완료되었다.

#### 4. 면책기간

- 상해 관련: 계약일 즉시 보장 개시
- 질병 관련 특약: 해당 없음 (상해보험 특성)

#### 5. 갱신 조건

- 3년 만기 자동 갱신 (최대 80세까지)
- 갱신 시 보험료 재산출 (사고 이력에 따른 할증 없음)
- 음주운전 사고 시 면책 처리 (보장 제외)

### 제7조 실손의료보험

#### 1. 상품 개요

| 항목 | 내용 |
|------|------|
| 상품명 | 실손의료보험 |
| 상품 유형 | 의료보험 (실손 보상) |
| 표준 월 보험료 | 60,000원 (40세 기준) |
| 보험기간 | 1년 만기 자동갱신형 (15년 재가입) |
| 납입기간 | 전기납 (1년) |
| 가입연령 | 만 0세 ~ 만 65세 |

#### 2. 보장 내역

| 보장 항목 | 보장 한도 | 공제금액 | 지급 기준 |
|-----------|-----------|----------|-----------|
| 입원 의료비 | 연 5,000만원 | 급여 20% / 비급여 30% | 실제 발생 의료비 기준 |
| 통원 의료비 (외래) | 1회당 200,000원 (연 180회) | 급여 10,000원 / 비급여 30,000원 | 실제 발생 의료비 기준 |
| 통원 의료비 (약제) | 1건당 100,000원 (연 180건) | 급여 8,000원 / 비급여 8,000원 | 처방전 기준 |

#### 3. 가입 적합 고객

- 의료비 부담을 실질적으로 줄이고자 하는 모든 고객
- 건강보험 비급여 항목(MRI, 초음파, 상급병실료 등)에 대한 보장 필요 고객
- 예시: 가입자D 최영미(1992년생, 서울 서초구 거주)는 잦은 외래 진료에 대비하여 실손의료보험에 가입하였다. 최설계(서울 지역)가 실손 단독 플랜으로 설계하였다. 최영미 가입자는 2026년 3월 감기 외래 진료비 85,000원을 CLM-2026-003 건으로 청구, 공제금액 차감 후 심사 완료(settled) 처리되었다.
- 예시: 가입자F 한지현(1988년생, 서울 마포구 거주)은 실손의료보험과 든든한 종합보험을 함께 가입하여 종합적인 의료비 보장 체계를 구축하였다.

#### 4. 면책기간

- 질병: 계약일로부터 90일 경과 후
- 상해: 계약일 즉시 보장
- 비급여 도수치료, 체외충격파, 증식치료: 연 50회, 350만원 한도

#### 5. 갱신 조건

- 1년 단위 자동 갱신 (보험료 재산출)
- 15년마다 재가입 심사 (건강 상태 재고지)
- 보험금 수령 이력에 따른 보험료 할증 가능 (연 200만원 초과 수령 시)

### 제8조 저축성 연금보험

#### 1. 상품 개요

| 항목 | 내용 |
|------|------|
| 상품명 | 저축성 연금보험 |
| 상품 유형 | 연금보험 (저축형) |
| 표준 월 보험료 | 200,000원 |
| 보험기간 | 종신 (연금 개시 후 사망 시까지) |
| 납입기간 | 10년납 / 20년납 |
| 연금 개시 연령 | 만 55세 / 60세 / 65세 선택 |
| 가입연령 | 만 19세 ~ 만 55세 |

#### 2. 보장 내역 및 연금 지급

| 구분 | 내용 |
|------|------|
| 연금 지급 방식 | 종신연금형 / 확정기간형(10년, 20년) / 상속연금형 |
| 예상 연금월액 (종신형, 65세 개시, 20년납 기준) | 약 850,000원 ~ 1,050,000원 |
| 사망 보험금 | 납입기간 중 사망 시 기납입보험료의 110% |
| 중도 인출 | 해약환급금의 50% 이내 (연 1회) |
| 세제 혜택 | 10년 이상 유지 시 보험차익 비과세 (월 150만원 이하 납입분) |

#### 3. 가입 적합 고객

- 은퇴 후 안정적인 연금 소득이 필요한 고객
- 장기 저축을 통한 세제 혜택을 원하는 고객
- 예시: 가입자E 정태우(1965년생, 대전 유성구 거주)는 은퇴를 5년 앞두고 노후 대비를 위해 저축성 연금보험에 가입하였다. 정설계(대전 지역)가 10년납, 65세 연금 개시, 종신연금형으로 설계하였다. 월 200,000원 납입으로 65세부터 매월 약 95만원의 연금을 종신 수령할 수 있는 플랜이다.

#### 4. 해약환급금

| 경과 기간 | 납입보험료 누계 | 해약환급금 | 환급률 |
|-----------|:--------------:|:---------:|:------:|
| 1년 | 2,400,000원 | 1,680,000원 | 70.0% |
| 3년 | 7,200,000원 | 5,760,000원 | 80.0% |
| 5년 | 12,000,000원 | 10,800,000원 | 90.0% |
| 10년 | 24,000,000원 | 24,480,000원 | 102.0% |

#### 5. 유의사항

- 10년 미만 해약 시 원금 손실이 발생할 수 있다.
- 연금 개시 후에는 중도 인출 및 해약이 제한된다.
- 공시이율 변동에 따라 실제 연금 수령액은 예시와 다를 수 있다.

## 제3장 공통 사항

### 제9조 (청약 철회)
보험계약자는 청약서를 받은 날로부터 15일 이내, 보험증권을 받은 날로부터 15일 이내에 청약을 철회할 수 있다. 다만, 진단계약, 보험기간 1년 미만 계약, 전문보험계약자 계약은 청약 철회가 제한된다.

### 제10조 (계약 전 알릴 의무)
계약자 또는 피보험자는 청약 시 과거 5년 이내의 질병 치료 이력, 직업, 취미 등 중요한 사항을 사실대로 알려야 한다. 고지 의무 위반 시 계약이 해지되거나 보험금 지급이 거절될 수 있다.

### 제11조 (보험료 납입 유예)
보험료 납입일로부터 납입유예기간(2개월) 이내에 보험료를 납입하지 않으면 계약이 실효(해지)된다. 실효 후 2년 이내에 연체보험료와 이자를 납입하면 부활(효력 회복)이 가능하다.

### 제12조 (분쟁 해결)
보험금 지급 관련 분쟁은 금융감독원 금융분쟁조정위원회에 조정을 신청할 수 있으며, 한국소비자원 소비자분쟁해결기준에 따라 처리된다.
